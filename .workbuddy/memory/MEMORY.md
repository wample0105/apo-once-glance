# 一目 Onceglance · 项目长期约定

## 项目性质

AI 原生截图工具（Agent 视觉层）。定位：**让 Agent 看见你的屏幕，替你把操作变成教程。**
产品公式：专业取字工具 的极短路径 + 同类产品 的人类标注手感 + MCP 生态接入标准 + 把写作交给 Agent。
CLI 名 `once`，品牌色 `#FF3B30`，协议 MIT。首发 Windows 11（Win 10 19045+），macOS 预留。

## 三方分工（第一性原理，任何设计都不能违背）

**人类负责操作与审美，工具负责感知与记录，Agent 负责理解与成文。**

推论出的硬边界：
- 不做文章编辑器、不做云服务/账号、不做聊天框、不做录屏、不做全天候监控、不内置云端模型。
- 工具只做本地感知：零 API Key、零云端上传、零遥测。
- 每个功能先定义 CLI/MCP 语义，再定义 UI；但每个 UI 功能也必须能脱离 Agent 独立使用。
- 坐标是第一公民：OCR 输出必须带分块 bbox，全链路统一物理像素域。

## 契约（冻结项，改必须升主版本）

- 退出码：0 成功 / 1 参数 / 2 捕获失败 / 3 OCR 失败 / 4 读写失败 / 5 权限被拒 / 6 黑名单。
- 统一 JSON envelope：`{ok, data, error, meta}`。
- 默认落盘 `Pictures\Onceglance`（macOS 为 `~/Pictures/Onceglance`），按日期分子目录。
- 命名 `HHmmss-<kind>-<shortid>.png`，同名 `.json` 为 manifest。
- **衍生图永不覆盖原图**（lineage 指回原图）。

## 设计约定

- 一套设计语言 + 一层平台适配，不做两套界面。
- 亮工作台 / 暗取景：主窗口亮色跟系统深浅色；覆盖层固定暗色，不跟随。
- 一目红只做点睛，不大面积铺色。
- **长截图采集只有一条规则**：框选完就开始，滚到哪截到哪，停手就把「完成」递到眼前。参考 同类产品，但砍掉它的「等待/采集」两态和独立的拼接进度页。结束三种等价方式：点「完成」/ `Enter` / 选区内双击；**永不自动完成**（怕把加载中的页面截断）；`Esc` 取消**不落盘**。接缝质检页只在有可疑接缝时出现，全部正常直接落盘。
- 长截图的 `Esc` 取消 ≠ PRD LONG-6 的"拼接失败不丢弃"：前者是用户主动不要，后者是工具没拼成、要给用户保底。两条并行不冲突。
- 覆盖层遮罩分两档：待框选 30%，拖动中 55%。
- 提示只有四类：轻提示 3s / 警告 5s / 错误不自动消失且必带退出码 / 进度带取消。
- **不用颜色单独传达状态**，错误必配文字与退出码。
- 破坏性操作只有一个方向：删除进系统回收站；不提供黑名单"本次放行"。
- 快捷键族：Windows `Alt+Shift+*` ↔ macOS `⌥⇧*`（避开 ⌘⇧A / ⌘⇧3/4/5 / ⌘⇧T 等系统占用）。
- **品牌标识已定稿：印章 · 甲骨目**（2026-09-18 用户拍板）。红底圆角方章 + 白色甲骨文「目」（横置眼形 + 中轴竖瞳）。**完整施工图（比例网格、安全边距 X=章体边长 25%、尺寸分级、四种变体、三种字标排法、禁用清单）在 `docs/ui-design.md` §5.7，细化页在 `docs/一目品牌Logo-主标细化与多端资产.html`。资产库在 `assets/logo/`（14 SVG + 29 PNG）。**

  - 字标下限：整高 **<56px 去掉英文行**，**<28px 不用字标**；24–40px 标题栏是"24px 章 + 界面字体文字"，不许把字标等比缩小。

## 工作方式

- 原文件只读不改，新产出写新文件；需要改既有文档时先复制到 `docs/04-备份区/` 再原地更新（PRD / ui-design / 说明书三份已于 2026-09-18 备份并升 v1.1）。

- 原型为自包含单 HTML，无外部依赖，可直接用浏览器打开核对。
- **验证手段：改完原型/提案页用静态断言或 DOM 探针复核，不要指望读截图**（当前模型读不了图，截图看了也是白看）。同一文件的多个 Edit 必须串行，并行会互相覆盖。
- **SVG 转 PNG 管线（本机可用）**：本机没有 sharp/resvg/ImageMagick，用 Chrome 无头栅格化——把源 SVG 的 `width/height` 替换成目标尺寸写成临时文件，再 `chrome --headless --disable-gpu --hide-scrollbars --default-background-color=00000000 --force-device-scale-factor=1 --window-size=N,N --screenshot=out.png file:///...`。**必须走 PowerShell 通道**（bash 通道无输出），要透明底必须带 `--default-background-color=00000000`。校验用 node 读 PNG IHDR（偏移 16/20 = 宽高，25 = 色彩类型，6 表示 RGBA）。
