第 1 步 · 安装 CLI 与 Skill（一次装齐）
一条命令同时安装或更新 CLI 与 Skill：自动校验下载文件，并适配 Codex 和通用 Agent Skills 目录。

方式一 · 终端

复制curl -fsSL --retry 3 --retry-all-errors --retry-delay 1 https://github.com/wample0105/apo-once-glance/releases/latest/download/install.sh | bash

方式二 · 交给 Agent

复制请帮我在这台电脑安装 OnceGlance 的 CLI 和 Agent Skill。请执行下面这条命令： curl -fsSL --retry 3 --retry-all-errors --retry-delay 1 https://github.com/wample0105/apo-once-glance/releases/latest/download/install.sh | bash 安装完成后，运行 once status --json 验证是否安装成功。
安装后重启 Agent，再运行 once status --json 验证连接。Windows 在 Git Bash / WSL 中执行，macOS 在终端执行。
