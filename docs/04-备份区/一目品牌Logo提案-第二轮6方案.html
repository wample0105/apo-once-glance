方案 07目 · Glyph 把汉字「目」做成取景框——名字、含义、图形三合一
浅色底 · 主标
深色底 · 覆盖层 / 暗取景
一目Onceglance
64 32 16（去上横，保红横）
尺寸压力测试
语义：「目」本身就是「眼」，也是「条目、目次」（教程的步骤）。汉字形状本身就是取景框，红横 = 「一」。一个图形说完名字。
延展：框内红横可替换成进度、选中态；「目」字骨架可做中文标准字与竖排印章。
风险：字标性强，英文场景（once 命令行 / GitHub）辨识依赖字标辅助；对不看汉字的海外用户只是"一个框"。
方案 08折页 · Fold 截图变成一篇教程文档——「替你把操作变成教程」的直译
浅色底 · 主标
深色底 · 覆盖层 / 暗取景
一目Onceglance
64 32 16（只留红折角）
尺寸压力测试
语义：折角 = 文档，红色折角 = 那张截图变成了文章。产品最终交付物就是一篇教程，这是最"结果导向"的一案。
延展：折角可做"正在生成"动效；图标家族天然覆盖导出、另存、Skill 文档等场景。
风险：「文档」符号极其常见（笔记、网盘、办公工具都在用），独占性弱，要靠红折角立差异。
方案 09图层 · Layer 三层错位堆叠——原图永不覆盖，版本一层层长出来
浅色底 · 主标
深色底 · 覆盖层 / 暗取景
一目Onceglance
64 32 16
尺寸压力测试
语义：三层 = 原图 / 标注 v1 / v2，红色永远在最上层（最新版本），也隐喻"一层层把图做成教程"。对应产品最硬的承诺：衍生图永不覆盖原图。
延展：层数可动态化（记录文件数越多层越多），做成"成长"型品牌资产；也适合做图层、版本、历史等功能图标。
风险：偏抽象，第一眼不一定联想到截图；与设计软件类产品（图层概念）的符号重叠。
方案 10括号 · Brackets 取景括号 + 红色焦点——最极简的一案，OSD 取景符风格
浅色底 · 主标
深色底 · 覆盖层 / 暗取景
一目Onceglance
64 32 16（去聚焦环）
尺寸压力测试
语义：左右括号 = 取景范围，红点 = 焦点。产品气质是"界面退后、内容是主角"，这案图形也是：留白极大，安静。
延展：红点位置可做焦点追踪动画；括号开合可做框选动效，是本产品交互的天然复制。
风险：过于克制，货架（应用商店/官网首屏）上冲击力不足；与某些"扫码/对焦"类图标近似。
方案 11桥接 · Bridge 两个方块一条红链——把屏幕递给 Agent
浅色底 · 主标
深色底 · 覆盖层 / 暗取景
一目Onceglance
64 32 16（只留红链节点）
尺寸压力测试
语义：左方块 = 你的屏幕，右方块 = Agent，中间红链 = MCP / CLI 桥接。产品最独一无二的能力就是这条链，它值得成为标识本身。
延展：红链可做"连接成功/正在传输"状态动画；方块内可替换成窗口、终端、对话等具体对象做功能图标家族。
风险：横长构图，方形 App 图标需要压缩间距；"两个方块连线"在开发工具类产品中不算罕见。
方案 12印章 · 甲骨目 朱红方章 + 甲骨文「目」——东方气质，落款感（已定稿）
浅色底 · 主标
深色底 · 覆盖层 / 暗取景
一目Onceglance
64 · 描边目 32 · 转实心眼 16 · 最小尺寸
尺寸压力测试
语义：朱红方章 + 白色「目」。字取甲骨文的目——横置的一只眼睛，中间一竖是瞳仁，这是汉字「目」最早的形状，也是「一眼看过去」这个动作本身的画像。印章 = 落款、署名、"这一笔是我画的"，与工具"给内容盖章"同构。
延展：瞳仁落在中轴上，可做加载动效的呼吸点；印章形态天然适合"已保存 / 已确认"的成功态标记。要与原型标题栏那枚品牌章同源，一处定稿、处处同图。
风险：整块红面积较大，与"一目红只做点睛"需权衡——大尺寸（应用图标 / 启动页）用实心章，界面内小尺寸改用线描版本。眼形是横向的，放进方形章里必须留足上下边距，否则会显得扁。32px 以下转为实心眼，32px 是描边目的底线。
建议第二轮推荐与 12 案总览
  1. 已定稿 方案 12 印章（甲骨目）：用户拍板字形取甲骨文的「目」——横置的眼睛 + 中轴瞳仁。理由：一、篆刻本就是「篆书 + 印章」的组合，把字换成象形字才算把它做"正"；二、甲骨目是四案里唯一不用人教就看得出是"眼睛"的；三、它同时表达"看"与"落款"，正好是「一目」二字。
  2. 尺寸分级（硬规则）：≥48px 用描边目（眼轮廓 + 竖瞳）；≤32px 转实心眼（白色实心眼 + 红竖瞳槽），线条不再靠细描边撑；32px 是描边目的底线。
  3. 方案 07 目：汉字正楷做标，中文场景记名效率最高，作为字标备用字形保留（不是主标）。
  4. 方案 08 折页 / 方案 11 桥接：分别对应"变成教程"和"接上 Agent"两个核心价值，建议作为品牌插画 / 官网 Info 图标复用。
  5. 方案 09 图层 / 方案 10 括号：图形干净，适合做功能图标（版本、取景、对焦）与加载动效。
  6. 方案 E 甲骨目 = 12 案的最终字形；F 金文目 / G 小篆目 / H 小篆朱文印作为品牌字体与物料延伸保留（官网长图、周边、包装上用篆书更出味），不上界面。
