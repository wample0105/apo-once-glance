从唐诗、宋词、元曲里找名字

中文名第六批 · 实测 23 个，5 个撞死，18 个在公开渠道上还是空的

这批翻了唐诗、宋词、元曲三大块。结论跟你想的可能相反：诗词里最值钱的不是名句本身，是名句里那个动作。 "欲寄彩笺兼尺素"——"尺素"早被人抢了；"何当共剪西窗烛"——"剪烛"还空着。 同样，"吾家洗砚池头树"值钱的不是"墨梅"，是"洗砚"；"韦编屡绝铁砚穿"值钱的不是"读书"，是"韦编"。 越像一句好词、越大伙儿都会用，越挤；越像某个行当里干活的专用词，越空。

筛到什么程度，我先说清楚：每个名字我都跑了公开渠道（阿里云商标、启信宝、爱企查、企查查、标库网）的第 9 类检索，查到障碍的写清楚撞到谁、注册号多少、商品项里到底有没有软件。没查到的写"未见占用"。但这不等于能注册——公开渠道有盲查期、有更新延迟，最终必须去商标局官网自己查一遍。这一步谁也替不了。

三条实测出来的规律

规律说明
一、值钱的是动词"何当共剪西窗烛"——"西窗"是景，抢手；"剪烛"是动作，没人要。"吾家洗砚池头树"——"墨梅"抢手，"洗砚"没人要。诗词里那个手上真在做的动作，是整句里最空的位置。
二、藏书词整片空着书巢、青箱、芸阁、缥帙、缥缃、邺架、架阁——这些词共同点是"书放在哪儿"。这类词几十年没人拿来做软件名，因为不够响亮。但对"给截图找个住处"这件事，它们答得比谁都准。
三、元曲这条线天然出不了好名我把元曲过了一遍，实话说：元曲用口语俗语写，几乎不产"案头雅词"。这批里唯一从元代捡到的是元末王冕那首《墨梅》。所以你要的"元"这一条，不是我偷懒没翻，是它本来就没货。

03六个站住的，按推荐度从高到低

下面这六个，第 9 类在公开渠道上都没查到占用。每个我都标了出处、对应到产品哪一步、以及它的真实缺点——缺点我不帮你藏。

优点

  • 两个字都是小学水平的字，念得出来、打得出来、记得住——这是第五批所有候选都没做到的。
  • 出处是南宋陆游自己给自己书房起的号，不是拼凑的，可以直接讲一个完整故事。
  • "书"直接标明产品服务的对象（文字、文档、资料）。

缺点 / 要盯的地方

  • 陆游这个斋号太有名，书房、书店、茶馆、民宿类同名很多，第 16 / 35 / 41 类大概率被占。第9类本轮未见占用，但这是重点核查对象。
  • "巢"字有人会读成贬义（"巢穴"），但对工具名不算问题。

  • 两个字都常用，输入法一打就出，无生僻字。

  • 会有人第一反应以为跟蜡烛、灯具产品有关（第11类、第4类）。
  • 顺带排掉一个近似词："挑灯"（陆游《冬夜读书》"挑灯夜读书"）也是好词，但辛弃疾"醉里挑灯看剑"太有名，杀气重，且"挑"字两读（tiāo / tiǎo），容易念错，不取。

  • 三个字有具体形像，一眼能看到画面，这在所有候选里是唯一的。
  • "一眼看到格子线"跟产品名"一目"在气质上是同一挂的。

缺点 / 要盯的地方

  • 三字名的注册难度比两字大，审查时可能被拆开比对。
  • "乌"字偏暗沉，跟一目红那种明快调性需要重新调和一下视觉。
  • 三个字里有"栏"字，可能被联想成对话框／专栏，指向不够干净。

对应产品哪一步书外面那层套子。产品做的正是给屏幕上抓到的东西套一层壳——原图加一个 json manifest，正好两层。
为什么它安全两个都是生僻字，独占性最高，基本不会撞。

优点

  • 跟"衍生图／分身"这个概念对得最准的一个词。
  • 青色是书衣的颜色，正好能接一目的视觉体系。

缺点 / 要盯的地方

  • 硬伤：两个生僻字，口头传播基本靠不住，必须长期配拼音 piǎo zhì，做搜索也吃亏。
  • 所以它排在这六个的最后，除非你决定"独占性优先、传播性让位"。

06最后这道工序，得你自己跑一遍

我做的是公开渠道预筛，有盲查期、有延迟。在提交注册之前，下面这几步必须做。

  1. 上官网查：打开 sbj.cnipa.gov.cn → 商标查询 → 商标近似查询。国际分类填 09，输入候选词（书巢 / 剪烛 / 洗砚 / 韦编 / 乌丝栏 / 缥帙依次查）。
  2. 只看一件事：每一项结果的服务项里，有没有出现 计算机程序（可下载软件）、可下载的计算机应用软件、计算机软件（已录制） 这三条中的任意一条。有，就是挡路；没有，就不挡。像"雷达""导航仪""电缆""大屏幕液晶显示器"这类硬件项，不构成软件障碍。
  3. 图形标另查一遍：印章标「甲骨目」用图形检索，2026-05-22 起官网已支持以图搜图（png/jpeg/jpg，≤2M）。
  4. 顺带查组合名：把"书巢云""书巢笔记"这类你可能顺手用上的衍生名一起查。前面「云蓝匠星」「心画师」就是被衍生名连累的反面例子。
  5. 类别布局：主打第9类（软件本体）；辅以第16类（纸品文具）、第35类（广告销售）、第42类（软件服务）。注意第42类是服务类，挡不住别人在第9类注册，别搞混。
