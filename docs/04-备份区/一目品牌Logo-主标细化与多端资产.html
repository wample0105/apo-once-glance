一目 Onceglance · 主标细化与多端资产 已定稿

主标方向已定：印章 · 甲骨目。本页是它的施工图——比例网格、安全边距、最小尺寸、字标定制、多端资产与禁用态，全部按此执行。
品牌红 #FF3B30 墨色 #1D1D21 资产 12 个 SVG + 27 个 PNG 2026-09-18 · 定稿
所有图形以 48×48 为基准网格绘制，等比缩放。矢量源文件在 assets/logo/，位图在 assets/logo/png/。
01比例网格 48 网格上的每一个坐标，都是可复现的
图形不是"看着差不多"画出来的。章体、眼形、瞳仁的位置关系全部落在 48 网格上，任何人按下面的数值重画，出来的必须是同一枚标。
章体
x=4 y=4 w=40 h=40 rx=10　圆角半径 = 边长的 25%，48 网格内缩 4 单位，留出光学呼吸。
眼形（目）
水平跨 8.5 → 39.5（宽 31，占章宽 77.5%）；垂直跨 14 → 34（高 20，占章高 50%）。左右到章体各 4.5，上下各 10——眼形横长，上下必须多留，否则显扁。
瞳仁
中轴 x=24，纵向 19.2 → 28.8（长 9.6）。端点不顶到眼形上下沿，两端各留约 1.6，避免糊在一起。
线宽
眼形与瞳仁同为 3.4，两端圆头（round）。等粗是甲骨象形字的本色，不许一粗一细。
居中
眼形与瞳仁的几何中心 (24,24) 与章体中心重合，不偏上不偏下。
02安全边距 X = 章体边长的 25%，四周不得少于 X
边距不够，标就会被旁边的文字、图标、图片边缘"咬"住。下面虚线框内是禁区，任何元素不得进入。
X 的取法
X = 章体边长 × 25%。以 48 网格计，X = 10 单位。
换算成像素
24px 章 → 边距 6px；32px → 8px；48px → 12px；512px 应用图标 → 128px。
最紧也不能少于
0.75X。低于这个值就直接换用"章体 + 文字随行"的排法，不要硬挤。
同排多个标
两个标并排时，间距按两个 X 计，不是共用一个 X。
背景要求
标下方的背景对比度需 ≥ 3:1。花哨照片、渐变上使用时，必须垫一块纯色底或加深遮罩。
03尺寸分级 一条硬规则：大尺寸描边，小尺寸实心
描边目靠两条细线表达"眼"，线条在 32px 以下会糊成灰边。所以 32px 起改用实心眼——用面积代替线条，形状不变、语义不变。
48px描边目 · 应用图标 / 启动页
40px描边目 · 标题栏品牌章上限
32px实心眼 · 切换点
24px实心眼 · 界面内 / 托盘
16px实心眼 + 瞳槽加粗 · 最小尺寸
禁用16px 以下不用本标
≥ 48px：描边目。眼形轮廓 + 竖瞳，线条感最足，是完整形态。
40–47px：仍可用描边目，但只限标题栏品牌章这种静态场景，不做动画。
32px 及以下：实心眼。白色实心眼 + 圆角红瞳槽，形状语义完全一致。
16px：瞳槽加粗（5.4 → 6 宽）。16px 下那一道竖线只剩 2px，不加粗会消失。
16px 以下：不使用本标。改用纯色方块，或退化为「一」字。这不是妥协，是不让标变糊。
不许中间态：不存在"44px 用实心"这种自由选择，切换点固定在 32px，避免各端各自为政。
04字标 lockup 章是主，字是辅，永不抢位
三种排法，按可用宽度选，不许自己临时拼。中文在上、英文在下并左对齐；章体与文字块的高度必须视觉齐平。
横版完整字标 · 章左字右 · 最小整高 56px
精简字标 · 去英文行 · 最小整高 28px
深底版 · 字色换 F5F5F7，不透明度不变
竖版字标 · 章上字下 · 居中轴对齐
中文「一目」
字号 = 章体边长 × 0.68（48 网格里即 27）；字重 500；字距 +1.6（约 0.06em）；颜色墨色。
英文「Onceglance」
字号 = 中文字号 × 0.41（即 11）；字重 400；字距 +2.6（约 0.24em）——英文小，必须靠字距拉开才不糊；颜色墨色 62%，永远比中文淡一档。
基线关系
中文基线比章体中心低 1 单位，英文基线再低 15（≈ 中文字号的 0.56）。文字块整体的视觉中心落在章体中心上，误差不超过 2 单位。
章字间距
文字块左缘距章体右缘 11.2 单位 ≈ 章体边长的 28%，即一个 X。不许更紧。
什么时候不许用字标
整高 < 56px 时去掉英文行，用精简字标；整高 < 28px 时（例如 24–40px 的标题栏）不用字标——标题栏里是"24px 章 + 界面字体文字"，不是把字标等比缩小。字标内 8px 的英文没有可读性，缩出来只会脏。
字体
字标用 PingFang SC → Microsoft YaHei → Noto Sans SC 系统栈。正式物料里文字必须转曲，避免跨机器字体替换走形；当前 SVG 内的 text 仅作排布示意。

打包一条命令：Tauri 项目直接用 npx tauri icon assets/logo/png/appicon-windows-1024.png，会自动生成 ico / icns / 各平台尺寸，不用手工拼。
macOS icns 手工法：把 appicon-macos 的 16/32/64/128/256/512/1024 按 icon_NxN.png 与 icon_NxN@2x.png 命名放进 .iconset，再跑 iconutil -c icns。
PNG 底色：全部 32 位带透明通道。托盘与 favicon 依赖透明，不要用白色底图替换。
macOS 菜单栏为什么无底：系统会给模板图标自动反色（浅色栏变黑、深色栏变白），带红底的方章在菜单栏里不出效果，所以那里用无底纯眼形。
06用色变体与禁用态 四种合法变体，六种禁止动作
变体是预先定义好的四套，按底色和工艺挑一套用，不要自己调色。

标准红章白目。默认用它，浅底深底都能放。

单色深墨色章、线条镂空。单色印刷、激光刻印、浅底文档用。

单色浅白色章、线条镂空。深底、照片、视频角标用。

线描版白底红章红线。极简排版、浅底大留白、两色印刷用。

以下六种做法一律禁止。右边一列是照抄进来的错误示范，谁改谁负责回滚。

拉伸变形等比缩放，宽高比永远锁定 1:1。

改圆角圆角固定为边长 25%，既不能改成直角也不能改成全圆。

瞳仁偏轴瞳仁必须在中轴 x=24，偏一点就不像"目"了。

丢瞳仁眼形不能单独当标用，那条竖瞳是"看"的核心。

换色只有 #FF3B30 与黑白四套。改色等于换品牌。

加描边或投影标本身不带轮廓、不带阴影、不加外发光。

落地接下来照这个顺序做
  1. 接进代码：标题栏品牌章、托盘、菜单栏、favicon 四处直接引用 assets/logo/ 的矢量，不许各画各的。原型的品牌章已按此换图。
  2. 打包图标：跑一次 npx tauri icon assets/logo/png/appicon-windows-1024.png，再把生成的 icns/ico 按平台替换。
  3. 规范沉淀：比例网格、安全边距、尺寸分级、字标参数已写进 docs/ui-design.md §5.7，改标必须同步改那一节。
  4. 待补（还没做的）：安装包界面截图用的品牌插图、官网首图、周边物料；这些属于市场物料，等产品形态稳定后再出，避免现在做了又改。
这一版是"能用"的定稿，不是"完美"的定稿。真正的检验在落地之后：把标放进 16px 托盘、放进深色覆盖层、放进安装包图标，看它在真实环境里是不是还认得出——认得出就不用再动，认不出再回来调尺寸分级，而不是重开一轮提案。
