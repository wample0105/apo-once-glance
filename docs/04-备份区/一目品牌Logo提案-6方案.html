语义：「让 Agent 看见你的屏幕」的直译。红瞳孔 = 品牌「点睛」，与「一目红只做点睛」的设计原则天然一致。
延展：瞳孔可替换为光圈 / 选区 / 加载环（"Agent 正在看"的状态动画），叙事空间最大。
风险：「眼睛」是视觉类产品的高频符号，独占性一般，靠红瞳孔和轮廓比例做出差异。

语义：O = Onceglance 首字母，也是镜头。快门光圈 = 「捕获」这个动作的机械隐喻，工具感最强。

语义：框选 + 光标 = 用户每天重复几十次的那个动作。谁用谁知道，学习成本为零。
延展：选区框可直接复用为产品内真实的选区样式（Logo 即界面的一部分）；可加四角手柄点做动效。
风险：截图类工具都爱用选区元素，需靠红色圆角 + 光标穿插的构图比例立差异；「Agent」叙事缺席。

语义：灰 = 屏幕上的文字，红 = 正在读取的那一行。同时是「一」字横线与 OCR 扫描线，产品差异能力（感知）直接上标。
延展：天然适合做加载 / 识别中动画（红线逐行下移）；横版构图对浏览器扩展、开屏页友好。
风险：横版比例做方形 App 图标需要加背景容器；与「文本编辑器」气质有几分相似。

语义：气泡 = Agent 对话，框 = 截图。「人截好、递给 Agent 写成文」，三方分工的故事讲得最完整。
延展：气泡内可换成序号①、勾、进度点等，做功能态 / 状态图标一整套家族。
风险：「气泡」容易往聊天软件联想；元素两层，16px 需简化内框，复杂度是六案中最高的。
建议推荐排序与下一步
  1. 首选 方案 01 取景一：与现有原型品牌章同源（四角取景框），落地零切换；「一」进了图形，名字与符号合一；深浅底、16px 表现都稳。
  2. 次选 方案 03 光圈 O：如果未来海外 / 英文场景权重高（once 命令行、GitHub 仓库、MCP 生态），字母标的传播效率更高。
  3. 方案 02 一眼：叙事最贴「Agent 的眼睛」，但符号撞脸率高，适合做品牌插画 / 空态插图而非主 Logo。
  4. 方案 04 选区：界面内复用性最好，可与 01 组合（Logo 用 01，产品内选区样式用 04 语言）。
  5. 方案 05 扫描一 / 方案 06 递图：分别适合做「识别中」加载动画与 Agent 协作插画，作为辅助图形家族储备。
选定方向后进入第二步：主标细化（比例网格、安全边距、最小尺寸）、字标定制、多端图标资产（应用图标 / 托盘 16-20px / favicon / 安装包）、深色模式与单色禁用态规范，全部进 ui-design.md 设计令牌。
