Agent 的眼睛，中文里该叫什么

中文名第七批 · 实测 17 个，7 个撞死，10 个在公开渠道上还是空的

你提的这个意象很关键：不是"我看得清"，是"它替我看"。 前六批测的全是"人自己看"那条线——一目、明鉴、观止、鹰隼、离朱，一百多个词，第 9 类洁净率 0%。 这批换了个问法：不在"怎么形容看得清"里找，改去"把看这件事交给谁"里找。结果一下就不一样了。

筛到什么程度，我先说清楚：每个名字我都跑了公开渠道（阿里云商标、启信宝、爱企查、企查查、标库网）的第 9 类检索，查到障碍的写清撞到谁、注册号多少、商品项里到底有没有软件。没查到的写"未见占用"。但这不等于能注册——公开渠道有盲查期、有更新延迟，最终必须去商标局官网自己查一遍。这一步谁也替不了。

最要紧的一点：换主语，比换形容词管用

前六批我们一直在干左边这件事——换各种词去形容"看得清楚"。这批改干右边：不换形容词，换那个"在看的人"。

三条实测出来的规律

规律说明
一、某条路 0% 的时候，别在形容词里继续找六批一百多个词，只要词根是"看/眼/明/镜/鹰"，洁净率就是 0。这不是"换个更好的词就能过"，是整个词族都在别人的护城河里。这种情况下唯一的出路是换词性——从形容词挪到动词，从"什么样子"挪到"谁在干"。
二、"视觉"是第 9 类最挤的位置海康威视、汉邦高科这些做摄像头监控的公司，必须把"看得清"的词全占了。我们挑"明眸""天目"，等于跟安防产业抢同一个词。他们守的是产品线，我们只是想要个好听的名字。
三、"递"这个动作天然空着代、寄、属、分、司、袭——这几个字的共同点是"把某样东西从 A 挪到 B"。这类结构在商业命名里几乎没人用，因为它没有画面感、不够响亮。但它跟"Agent 调用工具截图"这件事是同构的。空，是因为没人需要，不是因为我们运气好。

03六个站住的，按推荐度从高到低

下面这六个第 9 类在公开渠道上都没查到占用。每个我都标了出处、对应到产品哪一步、以及它的真实缺点——缺点我不帮你藏。

窥牖kuī yǒu 语义最准 第9类未见占用
不出户，知天下；不窥牖，见天道。其出弥远，其知弥少。 《老子》第四十七章
字面"窥"是从小孔往里看，"牖"是窗。合起来：透过一个小口子，看见外面整片天。
对应产品哪一步这一句几乎是在写我们的产品：人不出门、不盯屏，透过截图这一个"小窗"，Agent 就看见了整屏发生的事。"其出弥远，其知弥少"还暗合另一层——我们不做全天候监控，只在需要的那一下看一眼，看得少反而看得准。
第9类状况前案 32790646（2018 年申请，商品项含全套软件项）已被驳回，障碍已失效，这个词目前是空的。驳回不等于永久安全，但至少没有活的权利人在守。
英文名Onceglance 不动，中文名独立，不需要互译。

优点

  • 语义贴合度是这批里最高的一个："透过一个小孔看见大世界"＝"透过截图看懂整屏"，不用绕。
  • 出处是《道德经》，讲得出口，而且是"看得少才看得准"这个反直觉的意思，跟产品"不监控、只按需看"的性格完全一致。
  • 两个字都是现成的古汉语常用字，不是生造。

缺点 / 要盯的地方

  • 最硬的伤："窥"有偷看的味道。截图工具本来就最怕被说侵犯隐私，名字里再放一个"窥"字，等于自己往那个方向递话。这是真实风险，不是小毛病。
  • "牖"字生僻（yǒu），大多数人不认识，口头传播要长期配拼音。
  • 前案虽已驳回，但驳回理由不明，注册时仍可能被引证近似。
我的判断：单看"意思对不对"，它第一。加上"窥"字和隐私的冲突，它得往后挪。如果拿它当候选，建议只做内部代号或社区里的小名，不做正式品牌名。
代瞩dài zhǔ 本轮首选 第9类未见占用
"代"是替，"瞩"是注视。合起来就是三个字：替你看着。 两个都是现成的古汉语字，组合后是个新词
字面替你把眼睛放在那儿，一直盯着。
对应产品哪一步就是 Agent 调工具的整个动作：人不用自己在场，Agent 发指令，工具替它看这一屏，看完交回去。名字直接把"替"这个关系写出来了。
为什么它安全不含"眼/目/眸/镜"任何一个字，不跟安防和眼镜产业抢词；也不含任何竞争、宏大的味道，就是一个动作。
英文名Onceglance 不动。

优点

  • 零误读。"代"和"瞩"都是常用字，看一眼意思就到了，不需要解释。
  • 它把这个产品最独特的那一点（看的人不是人）直接写进了名字。前六批所有候选都没做到这一点，它们描述的都是人的体验。
  • 两个字笔画都轻，好写好打；组合成新词，独占性天然比现成词高。

缺点 / 要盯的地方

  • 它不是一句古诗、不是一个现成的典故，这是我们自己拼的。好处是独占，坏处是讲不出"出处故事"。
  • "瞩"字偏书面，日常口语里少用，品牌第一眼可能略显文气。
  • 读音 dài zhǔ 跟"代主""待煮"同音，口播时单独听要上下文。
我的判断：这批里最"可用"的一个。它不美，但它准，而且不撞。如果发布节奏紧、不想在名字上再耗一个月，它是能直接定下来的那一个。
寄目jì mù 强推 第9类未见占用
把眼睛寄出去——人不在场，目光还在。 古汉语里"寄目"有"托付目光、借他人之眼"的用法
字面"寄"是托付、寄放。把自己的眼睛寄放在别处。
对应产品哪一步最贴"委托"这个动作的一层：Agent 把我的"看"寄放在工具身上，工具替我在屏幕上待着。比"代瞩"多了一层"信任交付"的味道。
为什么它安全第9类未见占用。"寄"这个动作在软件命名里几乎没人用过。
英文名Onceglance 不动。

优点

  • 两个字都常用好写，"寄"自带文气但不生僻，念出来有节奏。
  • "把眼睛交出去"这个画面很具体，配合图标（印章 · 甲骨目）能讲成一个完整的动作。

缺点 / 要盯的地方

  • 硬伤：jì mù 跟"祭墓"完全同音。这是个不吉利的谐音，中文品牌名里这类坑不能装看不见。谁先听出来谁别扭。
  • 因为有这个谐音，它在口播和门店场景里都会打折。
  • 写起来像人名，第一眼不易判断是产品。
我的判断：意思和气质都好过"代瞩"，但那个谐音是实打实的减分项。如果很在意口播，它排在"代瞩"后面。
袭明xí míng 第9类未见占用 出处最硬
善行无辙迹，善言无瑕谪，善数不用筹策……是谓袭明。 《老子》第二十七章（"袭明"＝顺着事物的本性去做，明察而不露痕迹）
字面"袭"是承袭、顺着来，"明"是看得明白。整句意思是：做得好的，不留痕迹。
对应产品哪一步"善行无辙迹"——工具最好的状态是你不觉得它在：不弹窗、不打扰、不要求你先去配一堆参数，你按下快捷键它就在了。这正好是一目"极短路径"的产品性格。
为什么它安全第9类未见占用，"袭明"这个组合在现代商业命名里基本没人动过。

优点

  • 出处跟"窥牖"同一个级别（《道德经》），而且这半句"善行无辙迹"本身就是一个很好的产品理念。
  • "明"字跟"一目"的语义延续，能接得上。

缺点 / 要盯的地方

  • "袭"字现代汉语里的第一义是"袭击""抄袭"（突袭、沿袭、因袭）。放在品牌名前，第一眼的联想是负面的，需要靠文案去掰。
  • 整体意思偏抽象，不解释一遍听不出跟截图有什么关系。
  • 两个字都偏文，不够轻快。
分灯fēn dēng 第9类未见占用 意象最好
禅宗讲传法，叫"传灯"，也叫"分灯"——从这一盏上分出一支火，递给下一个人。 《景德传灯录》以降的禅门用语
字面从一团火里分出一支，给它自己的光。
对应产品哪一步把"看"分一份出去，让 Agent 也有一双眼睛——这就是你描述的那个功能本身。而且"这一盏还在，那一盏也亮了"，正好是"多一个使用者，不多一份成本"的软件本性。
为什么它安全第9类未见占用。第42类 59075116 有人在（含软件设计、SaaS、文档数字化扫描），但那是服务类，挡不住第9类，别搞混。

优点

  • 意象是这批里最暖的一个，讲出来有故事性，适合做品牌叙事。
  • 两个字都好写，念起来干脆。

缺点 / 要盯的地方

  • 它偏"灯"不偏"眼"。你要的意象是"Agent 的眼睛"，分灯说的是"把光传下去"，中间隔了一层。
  • "灯"字会把品牌往灯具、照明类目上带（第11类），需要额外解释。
司明sī míng 第9类未见占用 像人名
字面"司"是掌管，"明"是看得见。掌管"看得见"这件事。
对应产品哪一步把工具定位成"视觉这件事的管家"——不管内容、不做判断，只负责让该看见的看见。
为什么它安全第9类未见占用。带"司"字的词在软件命名里也少见。

优点

  • 跟"代"字族的思路同源：都是把"看"当成一件可以托付的事。
  • 两个字都常用，无生僻字，好念好写。

缺点 / 要盯的地方

  • "司"是姓，加上"明"，两个字凑一起极易被当成人名（司明、思明、斯明都是常见人名）。产品名里这个歧义不小。
  • "掌管"这个词味道偏重，像是要管控什么，跟"轻量小工具"的性格有点冲突。

06最后这道工序，得你自己跑一遍

我做的是公开渠道预筛，有盲查期、有延迟。在提交注册之前，下面这几步必须做。

  1. 上官网查：打开 sbj.cnipa.gov.cn → 商标查询 → 商标近似查询。国际分类填 09，按顺序查：书巢 → 代瞩 → 蜀素 → 窥牖 → 剪烛 → 寄目。
  2. 只看一件事：每一项结果的服务项里，有没有出现 计算机程序（可下载软件）、可下载的计算机应用软件、计算机软件（已录制） 这三条中的任意一条。有，就是挡路；没有，就不挡。像"雷达""导航仪""电缆""大屏幕液晶显示器"这类硬件项，不构成软件障碍——本轮"继明"的两件硬件商标就是这样，不挡，真正挡住的是另一件带全套软件项的。
  3. 顺手把"代"字族一起查：代瞩、代明、代视 三件一起递进检索框。同一个字族里只要有一件被引证，整族都会被拖累——「司视明」就是这么把"司视"拖下水的。
  4. 图形标另查一遍：印章标「甲骨目」用图形检索，2026-05-22 起官网已支持以图搜图（png/jpeg/jpg，≤2M）。
  5. 类别布局：主打第9类（软件本体）；辅以第16类（纸品文具）、第35类（广告销售）、第42类（软件服务）。注意第42类是服务类，挡不住别人在第9类注册——"分灯"第42类 59075116 有人在，但那不影响我们的第9类。
