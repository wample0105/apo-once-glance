# 一目 UI 设计规范 v1.0（Win + Mac 双平台）

> 日期：2026-09-17 · 状态：方案稿（三张设计稿见对话记录）
> 一句话方向：**一套自有设计语言 + 一层平台适配**。不做两套界面。

## 1. 为什么这样做

- 目标用户每天用的系统不一样，但产品是一个。界面主体（布局、颜色、卡片、隐私页）一套代码，两边行为一致，维护成本最低。
- Windows 11 系统设置和 macOS 系统设置都采用「左侧竖向导航」，这个布局两边用户都有肌肉记忆，是双平台的最优解。
- 只有跟系统习惯强相关的少数点做适配（见第 4 节），避免用户在自家系统上感到「这软件不像 Mac 软件 / 不像 Windows 软件」。

## 2. 设计原则

1. **亮工作台 / 暗取景**：主窗口（历史、设置）亮色；覆盖层（框选、标注、toast）统一暗色取景框语言，不跟随系统深浅色——截图瞬间界面必须退后，内容是主角。
2. **一目红只做点睛**：`#FF3B30` 仅用于激活态、强调、选区框，不大面积铺色。大面积红会制造焦虑，工具类产品要安静。
3. **隐私是卖点，外露不藏**：「Agent 与隐私」是左侧一级导航项，总开关、黑名单、审计日志一页看全。
4. **OCR 文字预览进卡片**：历史卡片露出识别出的文字，找图先看字——这是产品「感知」特色的直接体现。
5. **确定性延伸到 UI**：toast、错误提示的文案与退出码对应（「黑名单命中（退出码 6）」），人和 Agent 看到同一套事实。

## 3. 设计令牌（Design Tokens）

### 3.1 颜色

| 令牌 | 值 | 用途 |
|---|---|---|
| `--accent` | `#FF3B30` | 主操作按钮、激活态、选区框、品牌章 |
| `--accent-bg` | `#FFE9E6` | 导航选中底色（红色浅底，不用纯红） |
| `--accent-text` | `#B3271C` | 导航选中文字（配浅红底，对比度达标） |
| `--bg-primary` | `#FFFFFF` | 卡片、内容面 |
| `--bg-secondary` | `#F5F5F7` | 导航栏底、设置项分组底 |
| `--border` | `#E5E5EA` | 分隔线、卡片描边（0.5–1px） |
| `--text-primary` | `#1C1C1E` | 主文字 |
| `--text-secondary` | `#55555A` | 次要文字 |
| `--text-tertiary` | `#8E8E93` | 提示、时间戳、热键标注 |
| `--success` | `#1D9E75` | toast 成功态、审计日志 ok |
| `--error` | `#B3271C` | 错误、黑名单命中 |

覆盖层（暗色）专用：

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ov-surface` | `#1D1D21` | 工具条、放大镜、toast 底色 |
| `--ov-surface-2` | `#26262B` | 二级属性行 |
| `--ov-border` | `rgba(255,255,255,0.13)` | 覆盖层描边 |
| `--ov-fg` | `#F5F5F7` | 覆盖层文字 |
| `--ov-mask` | 黑 55% 遮罩 | 框选时压暗非选区 |

### 3.2 字体

| 用途 | Windows | macOS |
|---|---|---|
| 界面 | Segoe UI + Microsoft YaHei UI | -apple-system (SF Pro) + PingFang SC |
| 坐标 / 尺寸 / 文件名 / 日志 | Cascadia Code / Consolas | SF Mono / Menlo |

字号阶梯：11 / 11.5 / 12 / 12.5 / 13 / 15。页面标题 15、卡片标题 11.5–12、正文 12.5、辅助 11–11.5。字重只用 400 / 500。

### 3.3 间距与圆角

- 间距基数 4px，常用 8 / 10 / 12 / 14 / 16。
- 圆角：卡片 9–12px、按钮 8px、工具条 10px、toast 9px。macOS 端整体可 +2px（跟随系统更圆的观感），由令牌统一控制。
- 控件高度：主按钮 32px、次级按钮 30px、工具栏按钮 32px（快捷键兜底，允许低于触屏标准）；表单控件 30px。

## 4. 平台适配层（唯一允许差异的地方）

| # | 项目 | Windows | macOS |
|---|---|---|---|
| 1 | 窗口控制 | 右上，自定义标题栏（最小化/最大化/关闭） | 左上交通灯，隐藏原生标题栏仅保留红黄绿 |
| 2 | 快捷键文案 | `Alt+Shift+A` | `⌥⇧A`（Option+Shift） |
| 3 | 落盘路径文案 | `Pictures\Onceglance` | `~/Pictures/Onceglance` |
| 4 | 截图反馈 | 右下角 toast（贴任务栏侧） | 顶部右上横幅（贴菜单栏侧，参考系统通知位置） |
| 5 | 右键菜单 | 系统原生上下文菜单 | 同左，遵循 HIG 间距 |
| 6 | 圆角观感 | 基准 8px | 令牌整体 +2px |

其余一切（导航结构、颜色、卡片、隐私页、覆盖层、toast 组件本身）两平台一套代码。

**快捷键映射约定**：`Alt ↔ Option`，`Ctrl ↔ Cmd`，注册冲突时两端都提供改键界面（PRD SYS-3）。

**DPI**：macOS Retina 与 Windows 缩放（150%/200%）下，覆盖层坐标全部走物理像素域（manifest 已记录 `dpi_scale`），UI 控件按逻辑像素布局，选区框线宽 1.5 逻辑像素。

## 5. 布局与组件规范

### 5.1 主窗口（托盘左键呼出）

- 尺寸基准 780×560，最小 680×520。
- 自定义标题栏（48px 以下，含品牌章 + 窗口控制）。
- 左侧导航 148px：历史（默认选中）/ 标注主题 / Agent 与隐私 / 通用；底部版本号。
- 导航项一律 **icon + label**（业界通行：WinUI NavigationView、macOS 系统设置、Material 3 均如此；圆点留给状态语义，如标题栏 Agent 在线点）。图标选约定俗成的：历史=时钟、标注主题=笔、Agent 与隐私=盾牌、通用=齿轮；单色线性 16px，stroke 1.7，激活时随文字变红。
- 选中态：`--accent-bg` 底 + `--accent-text` 字 + 图标变 `--accent`；未选中图标灰。
- 历史页三段式：截图操作条（区域截图主按钮 + 窗口/取字/长截图次级按钮，均带快捷键标注）→ 搜索行（OCR 全文检索）→ 卡片网格。

### 5.2 历史卡片

- 缩略图区 76–110px，4:3 裁切。
- 信息三行：文件名（截断）/ 元信息（时间 · 原图或衍生图 · 标注步数）/ OCR 文字预览（「」包裹，截断）。
- 衍生图缩略图左下角显示红色序号角标，与原图区分。
- 悬停浮出操作：编辑 / 打开（进资源管理器）。

### 5.3 框选覆盖层

- 全屏暗遮罩（`--ov-mask`），选区 1.5px `--accent` 边框 + 四角白底红边手柄（9px）。
- 选区上方：尺寸提示（等宽字体，如 `812 × 486`）。
- 光标附近：放大镜（74px，8× 放大，十字线 + 像素坐标）。
- 松手后选区下方：快捷动作条（复制[主] / 取字 / 标注 / 长截图 | Esc 取消）。
- 全过程不抢键盘焦点；Esc / 右键取消，无任何副作用。

### 5.4 标注浮层（兜底标注）

沿用现有 `ui/editor.html` 的暗色取景框语言：主工具栏 + 上下文二级属性行 + 长按子类型菜单。本次不重构，只对齐令牌（红色、圆角、描边一致）。

### 5.5 toast

- 结构：状态点（7px，成功绿/错误红）+ 文案 + 可选动作。
- 文案模板：成功「已复制 N 字 · 本地完成」；失败带错误码「保存失败（错误码 4）· 路径已兜底」。
- 位置按平台（见第 4 节），自动消失 3s，失败态 5s 且不自动消失。

## 6. 无障碍

- 正文对比度 ≥ 4.5:1（`--text-secondary` #55555A 在白底为 7.4:1，达标；`--text-tertiary` 仅用于 ≥12px 非关键信息）。
- 全键盘可达：导航 ↑↓ 切换、Tab 走焦点、Esc 取消；焦点环 2px `--accent`。
- 动画只用透明度和位移（150–220ms），尊重系统「减少动态效果」设置。
- 不用纯颜色传达状态：错误必配文字与退出码。

## 7. 落地说明（Tauri 2）

- 颜色、圆角、间距全部走 CSS 令牌，平台差异用 `body[data-os="windows"|"macos"]` 切换（初始化时由 Rust 侧注入），不写死在组件里。
- macOS 隐藏原生标题栏 + `trafficLightPosition` 定制交通灯位置；Windows 用 `decorations: false` 自绘控制按钮。
- 快捷键注册走 Tauri global-shortcut，展示层做 `Alt+Shift+A ↔ ⌥⇧A` 的渲染映射，不存两份配置。
- 覆盖层窗口两平台统一 `transparent + always_on_top + skip_taskbar`，暗色主题不响应系统深浅色。
