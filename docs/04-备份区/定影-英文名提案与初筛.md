# 定影 · 英文名提案与初筛（2026-09-18）

**背景**：中文名已定「定影」（摄影工序：显影之后把影像永久固定住，使它不再变化）。原英文名 Onceglance 保留与否待定。本文档记录英文名候选方向与公开渠道初筛结果。

## 定影的英译参照（摄影术语，先用行话对行话）

| 中文 | 英文摄影术语 | 备注 |
|---|---|---|
| 显影 | develop / developing | 已被各种开发工具占用，方向放弃 |
| 定影 | **fix / fixing / fixer** | 行话正解；但 fix 族被维修类软件用滥 |
| 定影液 | fixer / fixing bath / hypo | hypo 是"海波"（硫代硫酸钠）的行话古称 |
| 底片潜影 | latent image | 见过的人少 |
| 成片 | still / still frame | still = 静帧，与"定"的语义最近 |

## 语义对照（定影 → 英文的四条路）

1. **行话派（fix/fixer/hypo）**：懂行的人秒懂，但 fix 族英文里被维修/金融占滥 —— 全灭。
2. **静帧派（still-）**：still 在摄影里就是"定格的帧"，与"定"同义 —— **方向最正**，但 SnapStill / StillFrame / Stilla 全被占，证明这个方向已被同行想到过。
3. **拉丁派（latens，潜影）**：雅但离"定"远，且有在位者。
4. **保留 Onceglance**：logo 与英文名早已绑定；"once glance"＝一眼，与"定影"是"看→定"的两半，故事能接上。
