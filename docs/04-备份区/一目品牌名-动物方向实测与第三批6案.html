03换了三回思路，才想明白一件事

前两轮我在"跟截图意思相近的词"里找，越找越挤。这一轮反过来问：截图到底是个什么动作，历史上有谁干过同样的事？

截图这个动作，说到底是两件事："把屏幕上的一块原样取下来"，和"取下来之后要能给别的人照着重做"。 这两件事，古代的手艺人都在做——而且各有一套专门的词。这些词有三个好处：有真实出处、有画面、但商业上没什么人用。

思路为什么这个方向有戏反面对照
A 取下来
拓 · 抄 · 摹		 把器物或书本表面的一层"原样转移到别的地方"，这门手艺有一整套词：拓、影抄、摹、扑粉。跟截图是同一个动作，只是介质从石头、纸变成了屏幕。 不要用"截""切""抓"这类直白动词——太通用，全被占了。
B 留下来才有用
底稿 · 样张		 截图不是为了"存"，是为了"给别人照着做"。所以"底稿""样板""样张"这一路的词，正好说的是产品交付出去以后那张图的作用——它就是别人照着做的底本。 不要用"图""谱""录"单字——单字太宽，一定有人占。上一轮「图录」就是这个毛病。
C 从行业生词里挑
不是挑好听的		 两轮的规律很清楚了：好听的词早就没了（写照、见微、澄观、重明鸟全撞），能活下来的都是某一行的生词。生词冷门这件事，在商标上是优点、在传播上才是缺点。 不要再从"成语""诗词名句"里挑。那些是所有人取名的第一站。
顺带说个具体的好处：生词冷门，但解释只要一句。而且一旦解释过，反而记得更牢—— "这名字哪来的？做拓片的行话。"比"这名字……挺好的"强得多。

04第三批 6 个（都过了公开初筛）

前两个我放了重点标。后面四个附了各自的短板，你看的时候别只看名字好听不好听。

粉本
fěn běn 首选 初筛干净

中国画工的行话，指"底稿 / 底样"。元明画论里常见这个词。

画工打底样，是在纸上沿墨线扎满细孔，把这张样覆在壁上或绢上，用一包粉（白垩或蛤粉）隔着孔拍打过去，粉透过细孔落在下面的画面上，留下一个个点；拿开样纸，依着这些粉点落墨，一幅画就"搬"到了新地方。
这个做法本身就叫扑粉，那张被反复用、拓到哪都算数的底稿，就叫粉本。 出处：中国画传统术语，元明以来画论常用（如元·夏文彦《图绘宝鉴》）；技法记载见历代画工口诀。上段为技法概述，非原文引用。
粉本 = 反复使用的底稿你截的那张图，被 Agent 拿去写成教程 → 那张图就是别人的粉本
扑粉 = 通过孔把图样"搬"到新地方截图 = 把屏幕上的一块"搬"到别的地方（记到文件、送到 Agent）
依点落墨 = 照底稿走一遍读者照教程做一遍

好

  • 公开渠道没查到任何企业占用，是这批最干净的之一
  • 跟产品动作是同一件事，不用绕
  • 两个字、软音、好念（fěn běn 都是上声转轻声，读起来顺）

短板

  • "粉"容易被误认成"粉色、化妆粉"，第一眼不知道跟截图有关
  • 需要一句解释才能立住（但只需要一句）
英文名建议：Onceglance 不动。中文若要配一个，用 Master（底稿 = master copy）比直译好。
定名前必须做：第 06 节的中国商标网检索。
留真
liú zhēn 首选 初筛干净

文献学的词，出自清末杨守敬的《留真谱》。

杨守敬去日本访书，见了大量中土已失传的宋元旧本。他把这些古书的首卷首页影刻下来，辑成一编，取名《留真谱》——所谓"留真"，就是让没见过原本的人也能看到它真实的样子，不至于被后世的翻刻、改字骗过去。 出处：杨守敬（1839—1915）编《留真谱》，1901 年刊行，中国最早的书影图录。这是一段可查的实在史实。
留真 = 把真实的样子留下来截图 = 把屏幕上真实的样子留下来
怕被翻刻改字骗 → 所以要留真怕口头转述失真 → 所以要截图（一图胜千言，就是这个意思）
《留真谱》= 一部图像汇编一目 = 把一堆截图攒成一份能交出去的成品

好

  • 公开渠道没查到企业占用
  • "留真"两个字本身就是产品价值主张——留住真实，不靠嘴说
  • 没有生僻字，念出来就是普通话常用音，不用教怎么读

短板

  • 字面偏文艺，硬工具的气质弱一点
  • "真"字在当下语境容易被往"真假"的争论上带
英文名建议：Onceglance 不动。Truecopy 可以备选。
影抄
yǐng chāo 初筛干净 有歧义

古籍版本学的专门词，明清藏书家的顶级手艺。

碰到一本极难得的宋版书，买不起或买不到，就借来一册，用薄纸覆在原本上，一笔一笔照描——连版框的大小、行款的疏密、字的笔意都照原样摹下来。这么做出来的本子叫影抄本，最有名的是明末毛晋汲古阁的"影宋抄本"，藏书家公认它"下真迹一等"。 出处：古籍版本学术语。"影抄本""影宋抄本"是藏书目录里的标准类目，汲古阁毛氏为其中代表。
影 = 照原样 / 影子截图取的就是屏幕的"影"
覆纸照描，一字不改截图不改内容（不是说截图之后不能标注，是"取下来"这一步不改）
"下真迹一等"截图不是原件，但足够替代原件（这正是这个产品的立足点）

好

  • 公开渠道没查到企业占用
  • 一个字"影"就把产品的意思说透了，而且是文化词不是技术词
  • "下真迹一等"这句话可以当品牌金句用

短板（要认真看）

  • "抄"字在中文日常语境里有"抄袭"的联想，跟"截图给别人用"这件事放一起，容易被误读
  • 在版本学里"抄"是中性的，但用户不在版本学里
英文名建议：Onceglance 不动。Facsimile 正是"影抄本"的英文对应词，是罕见的精准对译。
朱记
zhū jì 需复核

唐宋官印的一类形制，"红章"最早的名字之一。

唐宋的官印里有一类，印文直接就是"某某朱记"，尺寸小、字用楷隶而不作篆书，给级别不高的官署使用。所谓朱记，就是朱色的印记——那几个红字盖在纸上，就是官府认过的凭证。 出处：中国古代官印制度术语，唐宋官印著录中"××朱记"是常见印文格式。
朱记 = 朱红色的印记你的标记就是朱红（#FF3B30）圆角方章
盖在纸上 = 这份东西被认过截完图盖上标注，这份东西就能交出去了
官印是有权威的凭证"这是真的、我确认过"——截图在协作里的作用就是这个

好

  • 跟已定稿的 Logo 完全闭环：朱记、朱红、朱拓——这已经是三条线指向同一个意象了
  • 两个字、好念，不像生词

短板

  • 查到一家「朱记小眼镜」18183568（9 类，2016-12-07 至 2026-12-06），商品项里有 0901 计算机软件(已录制)，构成部分障碍
  • 「朱记」作为姓氏 + 记的招牌名，全国小店重名极多，品牌独特性偏弱
英文名建议：Onceglance 不动。Rubric 意外地贴——rubric 本义就是"红字"，在英文里还引申出"规程、评分细则"，正好对上"教程"这层意思。
摹本
mó běn 需你自己查

最不需要解释的一个。故宫的《兰亭序》神龙本，就是摹本。

照着原作临摹复制出来的本子叫摹本。王羲之《兰亭序》真迹不在了，今天大家看到的是唐代冯承素的摹本——它不是原作，但它把原作的样子留住了，所以几百年里所有人都认它。 出处：书画鉴藏通用术语。"摹"（覆纸照描）与"临"（对着看再写）是两种不同的复制方式，摹本更接近原样。
摹本 = 照原样复制的本子截图 = 屏幕的摹本
真迹没了，摹本还在起作用界面会变、软件会换，截图留下来的是当时真实的样子

好

  • 最好懂——说一句"屏幕的摹本"谁都明白，零解释成本
  • "摹"字本身就含"照着做"，跟教程天然同义

短板

  • 太常用的词，占用概率高，我没搜到明确企业占用，但也没搜到"干净"的证据——这一条必须你自己去查
  • "摹本"隐含"不是原件、是替代品"，作为产品名略有折价感
英文名建议：Onceglance 不动。
样张
yàng zhāng 需你自己查

印刷厂的行话。这批里最"接地气"的一个。

印刷厂开机之前先打一张出来，叫样张——看颜色对不对、字有没有掉、版有没有歪。样张是给"拍板的人"看的：他看了这张，才决定整批要不要这么印。 出处：印刷业通用术语，"打样""样张"是印前标准工序。
样张 = 先出一张，看对不对先截一张，看清不清、够不够用
样张是给拍板的人看的凭据截图是给同事、给 Agent、给读者看的凭据

好

  • 外行也能秒懂，不用讲典故——如果这一轮的核心诉求是"别再费口舌"，就是这个
  • 两个字，工整，界面里排字标也好看

短板

  • 同样没有拿到"干净"证据，且它是印刷业高频词，预判占用概率是这批最高的
  • 气质偏"厂"、偏传统制造，跟 AI 原生的调性差得最远
英文名建议：Onceglance 不动。Proof 可以做彩蛋——proof 在印刷里就是"样张"，在逻辑里是"证明"，一语双关。
这一批里我主动淘汰的（免得你重复问）： 「书影」——文献学术语本来很合适（拍书页样子），但一搜就出来重庆、北京、兰考三家"书影文化传媒"，北京那家还持有 2 个注册商标，撞了。 「初拓」——9 类已有人注册（2016-06-07 至 2026-06-06，含"计算机外围设备"，没有"可下载软件"项），目前在商标交易平台上挂着卖，报价 2.6 万。 这条路要说明的是：现成的标是可以买的，如果最后你就是想要某个被占的名字，花钱谈转让是一条正经路子，比硬申请被驳回划算。

如果让我替你收口，就这三个

理由不是"哪个最好听"，是哪个最不容易走到一半翻车。

1

朱拓 —— 综合成本最低

它不是孤立的选项，是跟已经花掉的工接得上的那一个：品牌色朱红、Logo 红方章、名字用朱砂拓印，三样是一套东西。改名的代价在这里最小——你连设计稿都不用重画，只要换字标里的字。

唯一的缺点是需要一句解释。但那句话很短："朱拓，拓片里用朱砂的那一种，最讲究、最贵。"

2

留真 —— 名字本身就是卖点

"留真"两个字不用解释就能感觉到在说什么，而且它描述的正好是这个产品解决的问题——文字转述会失真，所以要把真实的样子留下来。这句话可以直接印在官网首屏。

它跟文创、出版类品牌会有气质上的重叠，这是要接受的一点。

3

粉本 —— 意思最准，但要接受它冷

如果按"名字和产品动作的贴合度"排，粉本是 12 个里第一。截图就是给别人递一张粉本，这事说得不能再准了。

短板也清楚：第一眼没人知道这是什么。选它，等于接受"这个品牌名字需要被解释一次"。

叙录、影抄 我放在第二梯队，不是不好，是各有各的硬伤：叙录最干净但最冷，影抄最精准但"抄"字在中文里带贬义。你要是就喜欢这两个里的某一个，也能选，我照做，只是得把短板提前说清。

06定名前这一步，只能你来（我做不了）

我这两轮做的都是公开渠道搜索。它不是商标局的检索，不构成法律意见，也做不到"证明没冲突"。真正的结论只有官方检索能给。

第一步：查文字

打开 wcjs.sbj.cnipa.gov.cn（商标网上检索系统），进「商标近似查询」。先把你选中的那 1–2 个词查一遍，重点看四个类别：

类别管什么看什么
