# 定影 Onceglance UI/UX 评审报告（综合）

- **日期**：2026-09-26
- **评审范围**：主面板五个页面（首页 / AI / 通用 / AI 助手 / 诊断），对应 v0.2 当前构建
- **评审方式**：全部问题逐条核对源码定位（文件与行号见附录），以实机截图交叉验证显示结果；未经实机复核的项单独标注
- **级别口径**：P0=功能阻断，P1=功能缺陷，P2=一致性与信任打磨，P3=文案与细节

---

## 一、总体结论

主面板整体合格：信息架构清晰（首页=动作区+核心能力+最近记录三段式）、设置四 tab 分组合理、诊断页自检全绿。隐私叙事（BYOK、Key 只存系统凭据管理器、本地 OCR 永不联网、诊断报告不含截图内容）在同类工具中属于加分项，应继续保持。

问题共 16 项：**P0 ×1、P1 ×1、P2 ×7、P3 ×7**。P0 为功能问题（AI 问图当前必然报错），P1 为上线即存在的显示缺陷，其余为打磨项。

## 三、做得好的（保持）

- 设置顶栏「返回 + 四 tab」：轻工具的正确导航密度，页面跳转零适配成本；
- 隐私叙事完整：BYOK、Key 加密入系统凭据管理器、本地 OCR 永不联网、主动触发才发送、审计日志——信任感的核心来源；
- 内联删除二次确认：首击变「确认删除？」，3 秒不点回落，替代突兀的原生弹窗（`ui/js/main.js:873`）；
- 「测试连接」反馈完整：按钮进入「测试中…」禁用态，逐项回显延迟毫秒数或失败原因（`ui/js/main.js:854`）；
- AI 助手页客户端状态机完整：未接入 / 已写入等待首次连接 / 已接入 / 未检测到客户端，四态各有对应操作；
- 快捷键支持点击录制改键，冲突即时反馈，Esc 退出不改动（SYS-2/3）；
- 拉取模型列表带 loading 与结果计数；窗口尺寸记忆；详情页 1:1 原图直出；
- 空状态带下一步引导（如「还没有截图，按 Alt+Shift+A 试一次」）；
- 颜色、圆角、间距全局走 `tokens.css` 设计令牌，五页视觉一致。

## 四、建议动手顺序

1. **P0 + P1 同一次构建修复**（都在后端字段/逻辑层）：`get_settings` 补 `save_root` / `save_dir_writable` 两个字段；首页徽章改双角色判定 + 保存配置自动补默认视觉角色；发布前在 AI 页手动指定一次默认视觉模型作为临时解；
2. **P2 小改一次清掉**：徽章中性色、快捷键语义统一、箭头图标、tab 命名、MCP 说明上移与路径次要化、诊断总结态；首页信息架构（#7）先做产品定位确认再动；
3. **P3 随版本打磨**：空态文案、自检按钮配色、删除提示、字号密度、对比度审计、绿点 tooltip；#14 实机复核后单独定；
4. 修完真机回归，不提交，等用户验收授权。
