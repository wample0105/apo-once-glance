## 1. 设计依据与原则

### 1.1 三条来自 PRD 的硬约束

1. **一套引擎，两个入口**：人类界面上的每个动作，都能在 CLI/MCP 找到同一个后端调用。界面上不允许出现只有 UI 才能做的事。
2. **确定性延伸到界面**：错误提示的文字必须和退出码对得上（"已拦截 · 黑名单命中（退出码 6）"）。人和 Agent 看到同一套事实。
3. **隐私是卖点，要外露**：开关、黑名单、审计三样东西各留在别人家设置页的深处，这里放在一级导航。

### 1.2 七条交互原则

| # | 原则 | 落到具体做法 |
|---|---|---|
| 1 | 截图这条路上，界面越少越好 | 主路径（快捷键 → 框选 → 复制）全程零窗口。只有用户主动点了"标注"才出现编辑器 |
| 2 | 覆盖层像相机取景框，主窗口像工作台 | 覆盖层永远暗色、永远置顶、永远不抢焦点；主窗口亮色、跟系统深浅色 |
| 3 | 每个动作都要有键盘路径 | 从呼出到保存，全程可以手不离键盘。鼠标是加速手段，不是前提 |
| 4 | 结果先给，过程后说 | 图片先落盘进剪贴板，OCR 在后台跑。用户拿到图不等于要等 OCR |
| 5 | 主按钮跟着默认动作走 | 动作条主按钮永远是当前"截图后默认动作"，不让用户记两套动作 |
| 6 | 出错必须给下一步 | 不说"操作失败"，说"保存失败（退出码 4）· 图片已在剪贴板，可换目录重试" |
| 7 | 破坏性操作只有一个方向 | 衍生图永不覆盖原图；删除一律进系统回收站（Windows 回收站 / macOS 废纸篓） |

## 2. 界面清单与信息架构

```text
定影 Onceglance
├─ 全局层（随时可呼出）
│   ├─ 捕获覆盖层：区域 / 窗口 / 全屏 / 延时倒计时
│   ├─ 长截图浮层：框选即开始 → 滚动采集（滚动中实时拼接）→ 接缝质检（仅可疑时出现）
│   ├─ 标注编辑器（全屏浮层）
│   └─ 通知层：轻提示 / 警告 / 错误 / 进度
├─ 常驻入口
│   ├─ Windows：系统托盘图标（左键主面板，右键菜单）
│   └─ macOS：菜单栏图标（单击菜单，双击主面板）
├─ 主面板（780×560，详情页 1024×680）
│   ├─ 历史工作台（默认）
│   ├─ 资产详情（从卡片进入）
│   ├─ 标注主题
│   ├─ Agent 与隐私
│   ├─ Agent 接入
│   ├─ 通用（含快捷键、历史与存储）
│   └─ 诊断
└─ 首次启动引导（一次性）
```

左侧导航从 4 项变成 6 项，顺序与理由：

| 位置 | 导航项 | 图标 | 理由 |
|---|---|---|---|
| 1 | 历史 | 时钟 | 最高频，默认选中 |
| 2 | 标注主题 | 笔 | 高频调，放前面 |
| 3 | Agent 与隐私 | 盾牌 | 差异化卖点，不藏 |
| 4 | Agent 接入 | 插头 | 接入引导 + 状态 + 冒烟自检，一次配好不用再来 |
| 5 | 通用 | 齿轮 | 低频设置 |
| 6 | 诊断 | 听诊器 | 出问题时才来，放最后但一眼能找到 |

底部保留版本号行；版本号左侧增加一个"状态点"：绿=全部正常，黄=有可修复项（如热键冲突），红=捕获不可用。点它直接进诊断页。这是把 P0-13 的 doctor 变成常驻健康指示。

## 3. 双平台差异总表

规则不变：**只有跟系统习惯强相关的做适配，其余一套代码。**

| # | 项目 | Windows | macOS |
|---|---|---|---|
| 1 | 常驻形态 | 任务栏右下托盘图标 | 菜单栏图标（Template Image，自动适配深浅色；Dock 默认不显示） |
| 2 | 呼出主面板 | 左键单击托盘图标 | 双击菜单栏图标；或单击后选"打开主面板 ⌥⇧H" |

| 4 | 右键菜单 | Win32 原生菜单，48px 项高，带图标列 | NSMenu，HIG 间距，设置项带 ⌘, 快捷键 |

| 9 | 打开所在位置 | 资源管理器 `explorer /select,` | 访达 `open -R` |
| 10 | 删除到回收站 | 回收站 `SHFileOperation` | 废纸篓（可"放回原处"） |
| 11 | 提示位置 | 右下角，贴任务栏上方 12px | 右上角，贴菜单栏下方 12px |
| 12 | 错误级提示 | 常驻提示条 | 常驻提示条 + 同时发一条系统通知 |
| 13 | 窗口圆角 | 基准 8px | 令牌整体 +2px |
| 14 | 窗口控制 | 自绘标题栏，控制钮在右上 | 原生交通灯在左上，隐藏标题栏 |
| 15 | 圆角/字体 | Segoe UI + 微软雅黑；等宽 Cascadia Code / Consolas | SF Pro + 苹方；等宽 SF Mono / Menlo |
| 16 | 屏幕坐标系 | 物理像素；多屏虚拟桌面原点可为负值 | 物理像素（Retina 已按 1x 逻辑坐标 × scale）；Y 轴原点同为左上 |
| 17 | 混合 DPI | 150% 主屏 + 100% 副屏常见，必须逐屏换算 | Retina 2x + 外接 1x，同样要换算 |
| 18 | 滚轮注入 | SendInput 合成滚轮 | CGEvent 合成滚动，需辅助功能权限 |
| 19 | 注册表/配置位 | 设置存 `%APPDATA%\Onceglance\` | `~/Library/Application Support/Onceglance/` |
| 20 | 开机自启 | 任务计划程序（非注册表 Run，便于声明权限） | LaunchAgent plist |
| 21 | 更新检查 | 手动点"检查更新"，打开 Releases 页 | 同左，手动 |
| 22 | 深浅色 | 主窗口跟随系统（可强制）；覆盖层固定暗色 | 同左 |

## 4. 逐界面交互设计

### 4.1 首次启动：自检与引导

**目标**：从安装完到完成第一次截图，中位耗时 ≤ 3 分钟（PRD §11 验收）。不阻断、不要求接 Agent。

**结构**：一个 640×460 的卡片窗口，三步，可上一步/下一步/跳过。

| 步骤 | 内容 | 交互细节 |
|---|---|---|
| 第 1 步 · 环境自检 | 5 行检查项，逐行亮起：实例、热键、捕获、落盘目录、OCR 引擎 | 每项 ≤ 400ms，全部跑完显示"3 项通过 / 1 项需处理"。失败项带"修复"按钮，能自动修的自动修（重注册热键），不能修的给指引（macOS 屏幕录制权限 → 直接打开系统设置对应面板） |
| 第 2 步 · 试一次 | 大字提示"按下 ⌥⇧A 框选任意区域试试"，旁边一个"不知道怎么按？"展开显示键名对照表 | 用户完成一次截图，这一步自动打勾并继续。截图结果在窗口内以缩略图回显 + 提示"已复制，可以直接粘贴了"。这一步是全流程最关键的一环：让用户在引导里就完成第一次成功 |
| 第 3 步 · 接 Agent？（可跳过） | 三个按钮：安装 CLI 与 Skill / 配置 MCP / 先跳过 | 点任一进入对应引导页（见 §4.10）。安装卡即一条命令装齐 CLI 与 Skill（终端复制命令，或复制整段提示词交给 Agent 代跑）；选择"先跳过"不产生任何提示，下次不再出现 |

**完成页**：一句"定影已在后台运行，随时按 ⌥⇧A 截图"，加一个"打开主面板"按钮。

**平台差异**：macOS 第 1 步必须有屏幕录制权限项，且此项未通过时第 2 步的"试一次"要置灰并说明原因（否则用户会以为是软件坏了）。

**状态与边界**

- 自检中窗口可关闭，关掉即视为跳过引导。
- 引导只出现一次；设置页"通用"底部保留"重新看一遍引导"入口。
- 自检发现的不可修问题（如落盘目录不可写），引导内直接给"换一个目录"，不在设置页绕。

**macOS 菜单栏**：单击出菜单，结构同上，差异在：

- 首项改为 `关于定影`（HIG 惯例），设置项写成 `设置…  ⌘,`，退出写成 `退出定影  ⌘Q`。

- 菜单底部一行灰字显示最近一次 Agent 调用时间（如"Agent 最近调用 14:32"），人在菜单栏就能确认 Agent 有没有在动。
- 双击图标 = 打开主面板（多给一条快速通道）。

**共同规则**

- 菜单项文字与快捷键 chip 右对齐，禁用态用 40% 透明度。
- "暂停截图热键"被勾选时，托盘图标显示暂停标记，且所有全局热键不再响应（但 Agent 接口不受影响，这是刻意的：避免用户为了玩游戏把 Agent 也一起关死）。
- 退出前若有未保存的编辑器浮层，先提示一次。

### 4.3 捕获覆盖层：区域 / 窗口 / 全屏 / 延时

这是本产品人类侧最重要的界面，一个动作没做顺手，产品就不成立了。

#### 4.3.1 状态机

```text
S0 热键呼出（≤200ms 出现覆盖层）
 └→ S1 待框选：全屏 30% 遮罩 + 十字光标，放大镜跟随
      ├ 鼠标移动 → 光标下窗口半透明高亮 + 窗口标题 chip
      ├ 单击左键 → 捕获该窗口 → S4
      ├ 按下左键拖动 → S2
      ├ 空格 → 锁定窗口模式，此后 Tab 在窗口间轮换，Enter 确认
      ├ Alt 按住 → 强制区域模式（临时关掉窗口吸附）
      └ Esc / 右键 → 取消（不落盘、不动剪贴板）

S2 框选中：遮罩升到 55%，选区恢复原亮度
      ├ 实时尺寸提示（选区上方居中，等宽字体，物理像素）
      ├ 放大镜（跟随光标，74px，8×，十字线 + 像素坐标）
      ├ 边缘吸附：距屏幕边/窗口边 ≤8px 时吸附，出现 1px 高亮提示线
      ├ Alt 按住 → 临时关闭吸附（用于精确框选）
      └ 松手 → S3

S3 已框选：选区保持，8 个手柄（四角 + 四边中点，白底红边 9px）
      ├ 拖选区内部 = 平移；拖手柄 = 改尺寸
      ├ 方向键 = 移动 1px；⇧+方向键 = 移动 10px
      ├ ⌥/Alt+方向键 = 调右下边界 1px；⌥⇧+方向键 = 10px
      ├ 动作条（智能翻转，见下）
      ├ Enter / 双击选区内 = 执行默认动作
      ├ T / A / L = 取字 / 标注 / 长截图
      └ Esc / 右键 → 取消

S4 执行：覆盖层立即隐藏自身 → 捕获 → toast
```

#### 4.3.2 动作条

位置：选区下方 8px；下方可用空间 < 56px 时翻到选区上方（翻转时保持左对齐到选区左边，超出屏幕则贴边）。

内容与顺序（主按钮永远是当前"截图后默认动作"）：

```text
[ 复制图片 ]  取字  标注  长截图        Esc 取消
   ↑ 主按钮，带当前快捷键 chip
```

- 按钮点击和键盘等价：Enter=主按钮，T=取字，A=标注，L=长截图，C 或 Ctrl/⌘+C=复制图片。

- 动作条本身不参与截图（它是覆盖层的一部分，捕获前先隐藏）。

#### 4.3.3 放大镜

| 项 | 规格 |

- **全屏**：主面板操作条"全屏"按钮，点击直接捕获主屏；按钮右侧一个下拉三角，展开"主屏 / 屏幕 2 / 所有屏幕"（P0-02 的 `--screen all` 在 UI 上的唯一入口）。
- **延时**：主面板"区域截图"按钮上右键（macOS 长按）→ 1 / 3 / 5 秒菜单。选定后下次该模式默认带延时，动作条旁显示`延时 3s` chip 可快速关掉。延时期间屏幕中央显示大号倒计时（48px 等宽），任意键取消并提示"已取消"。

| 项 | Windows | macOS |
|---|---|---|
| 不抢焦点 | `SW_SHOWNOACTIVATE` 显示窗口 | 非激活面板（nonactivating panel），能收键盘事件但不抢前台应用的焦点 |

- Esc 取消 100 次，必须 0 残留临时文件、0 剪贴板污染（PRD CAP 验收）。
- 选区小于 4×4 物理像素时视为误触，直接取消并给轻提示"选区太小了"。
- 混合 DPI 下所有尺寸提示显示物理像素，两个屏幕上框同一片区域数字应当不同（这是对的，不要"看起来一致"）。

### 4.4 长截图：框选完就开始，滚到哪截到哪

PRD 把它列为最高风险项。但"让失败看得见、改得动"是质检阶段的事；采集阶段的第一职责是**别让人分心**——这时候用户眼睛盯着被截的内容、手在滚，任何要求他"先点一下开始、滚完再点一下完成"的设计都在跟他的注意力抢位置。

所以采集阶段只有一条规则：**框选完就开始，滚到哪截到哪，停手就把「完成」递到他眼前。**

三个阶段：

**阶段 1 · 框选即开始**

- `Alt+Shift+L` 直接进长截图；如果已经在覆盖层里框好了，按 `L` 沿用当前选区，不再框第二次。
- 选区只能拖上下边（横向不拼接，所以左右不放开，免得用户以为能截宽表格）。
- 松手的那一帧就是第 1 段。**不需要再点"开始"。**

**阶段 2 · 滚动采集**

滚轮在屏幕任何位置都生效，不用把鼠标对准选区。

滚动中选区边框是红实线；停手超过 0.4 秒变成红虚线，表示"已暂停，随时继续"——不用文字解释，边框自己说话。

滚多少接多少。结束条贴在选区下沿外侧（不遮内容，也不飘到屏幕另一边去）：

```text
┌──────────────────────────────────────┐
│                                      │
│           （滚动中的内容）             │
│                                      │
│                                      │
│ 已 4 段 · 2180 px          完成 ↵   × │  ← 停手 0.4 秒后浮出
└──────────────────────────────────────┘
```

结束方式给三种，任选，不用背键位：

| 方式 | 什么时候顺手 |
|---|---|
| 点「完成 ↵」 | 手正握着鼠标、视线刚好扫到结束条 |
| 按 `Enter` | 键盘手 |
| 在选区里双击 | 鼠标已经在选区里，不用移出去找按钮 |

结束条的行为：

- 滚轮一动，它淡出（0.15s）；停手 0.4 秒，淡入。出现和消失都不打断滚动。
- 滚不动了（连续两帧完全相同）：文案变成「看起来到底了 · 完成 ↵」，按钮脉冲一次。**仍然不自动完成**——页面还在懒加载图片时自动完成会拦腰截断，这类投诉最难查。
- 往回滚（向上）：不产生新段，只让用户回去确认位置，结束条左侧短暂显示「回滚中 · 不记录」。裁剪放到质检阶段做，采集阶段不引入裁剪 UI。
- 自动消除了固定顶栏/侧栏时，结束条上以一句话告知「已消除固定顶栏」并给一个「撤销」，不做成面板。
- `Esc` 取消：**不落盘**，提示「已取消长截图」。

> 这里要分清两件事，别混了：**LONG-6 要求的"拼接失败时输出已成功部分、不静默丢弃"仍然成立**——那是工具没拼成，责任在工具，不能让用户的采集白费。而用户**主动按 `Esc`** 是另一回事，他就是要取消，这时候还塞给他一张图比丢掉更烦。**失败保底，取消就是取消。** 真想留下半截的人有更直接的路——按「完成」，完成就是"接受现在这些"。（本节早先版本写的"取消后输出已成功部分"作废。）

**阶段 3 · 接缝质检（大多数时候看不到这一页）**

滚动过程中已经在实时拼接，所以**没有单独的"正在拼接"等待页**，结束条上的段数和高度就是进度。

- 全部接缝正常 → **不弹质检页**，直接落盘 + 进剪贴板 + 提示「长截图已保存 · 12 段 · 12480px」。
- 有可疑接缝 → 才打开质检页，标题直说「3 处需要看一眼」。

```text
┌────────────────────────────────────────────────────────────┐
│ 3 处需要看一眼 · 高 12480 px        全部接受   确认并保存    │
├──────────────────────────────┬─────────────────────────────┤
│                              │ 接缝 1 · 第 1038px 行        │
│      〔纵向滚动预览〕          │ ┌─────────┐ ┌─────────┐     │
│      可疑接缝黄虚线标出        │ │ 接缝前 60px│ │ 接缝后 60px│  │
│      当前选中红实线标出        │ └─────────┘ └─────────┘     │
│                              │ [−10][−1] 接受 [+1][+10]    │
│                              │                             │
│                              │ 其余 8 处正常 · 已折叠        │
├──────────────────────────────┴─────────────────────────────┤
│ 内存峰值 412MB · 高度超 16000px 时可分段导出                 │
└────────────────────────────────────────────────────────────┘
```

- 列表**只列可疑接缝**，正常的折叠成一行。拿 8 条正常项去淹没 3 条要看的，等于没做。
- 主操作是「全部接受」——多数可疑接缝其实没问题，用户扫一眼"接缝前/接缝后"两张对比就够了。
- `−10 / −1 / +1 / +10` 调整该接缝偏移量（像素），点一次改一次，预览 200ms 内刷新。调整或接受之后这一条标记为「已接受」，不再占位置。
- 左侧点虚线接缝 → 右侧列表定位到对应项；右侧鼠标移到列表项 → 左侧预览高亮该接缝。
- 键盘：`↑↓` 切换接缝，`J/K` 微调 −1/+1，`⌘/Ctrl+Enter` 确认保存。
- 置信度只给「要检查 / 正常」两档，不显示小数——用户不关心 0.83 和 0.79 的差别，只想知道哪个该看。
- 高度 > 16000px 时出现「分段导出」，给 4000/8000/16000 三档，导出为 `xxx-part1.png`。
- 保存后：落盘 + 进剪贴板 + toast「长截图已保存 · 12 段 · 12480px」，manifest 记录段数、原始帧数、人工修正次数（修正次数进 manifest 是刻意的，方便以后回看当初哪里不靠谱）。

**参考 同类产品，我们去掉了两样东西**

同类产品 的长截图流程是「等待开始（蓝框）→ 点开始 → 采集中（红框）→ 点保存/复制」，右侧还有缩略预览和绿/红匹配点。它"滚轮滚、自动认重叠、实时拼"的核心我们照搬，去掉两处：

1. **等待/采集两态**。框选完还要再点一下"开始"，多一次点击、多一次犹豫；我们从松手那一帧就开截。
2. **独立的拼接进度页和右侧缩略预览**。采集时用户的注意力应该在内容上，给他一张缩略图，他就会去看缩略图。进度直接写在结束条上就够了。

### 4.7 标注：截完直接画（对齐 同类产品 交互）

**目标**：一张 5 步序号图 ≤ 60 秒完成（PRD ANN 验收）。所以默认值必须有品位，用户不调参数就能出图。

**交互总纲（v1.1 改版，采纳 同类产品 的五个关键点）**：

1. **标注发生在覆盖层上，不进"编辑器窗口"**。框选完成后工具栏直接就是标注工具栏，画完点保存/复制即走——"截图"和"标注"是一个动作，不是两步。原来的"按 A 进编辑器"作废。
2. **工具栏贴选区下沿浮动**（无空间依次取上方、右侧），跟随选区移动，不是窗口顶部的菜单条。
3. **两段式工具栏**：第一行工具 + 撤销重做 + 保存/复制；第二行属性行随工具变。
4. **橡皮擦**：点一下删掉单个标注，比"选中再按 Delete"快。
5. **每个工具 tooltip 带名字和快捷键**（同类产品 的"记号笔 (Ctrl+4)"式）。

**保留的差异点（不照抄 同类产品）**：

- 不加自由画笔 / 记号笔（v1）：教程标注的主路径是序号+箭头+框，手绘线条在教程图里大多显脏，椭圆已覆盖"圈一圈"的需求。列 P2 候选。
- 不做"贴到桌面"（同类产品 的招牌功能）：超出"感知与记录"边界，列为 G-9 候选。
- OCR 不进工具栏：覆盖层已有"取字"入口，重复入口只会让人犹豫。

**同一组件、两个入口**：① 覆盖层——刚截完直接画；② 历史——工作台卡片 / 详情页 / 长截图质检页"编辑"进入，同一组件加载已有图。Agent 生成的衍生图再编辑走入口 ②。

**布局**（暗色取景框语言，工具栏浮在选区下沿）


|---|---|---|---|

**关键规则**

- 任何工具下按 `Esc`：只取消当前这一个未完成的绘制（画一半的箭头、框选中的裁剪区），已完成的对象不受影响；选择工具下 `Esc` 取消选中。
- 属性行随工具切换：箭头/矩形/椭圆给颜色+线宽（矩形、椭圆多一组"描边/填充/描边+浅填充"），文字给颜色+字号，序号给颜色+起始值+样式，高亮给不透明度，马赛克给三档强度。状态栏同步显示当前工具的一行操作提示。
- 属性控件一律"效果预览"化（对齐 同类产品）：序号样式的三个按钮内直接渲染真实效果（实心圆"1"/描边圆"1"/纯数字"1"，颜色跟随当前选中色），马赛克三档按钮内渲染对应粗细的真实纹理——用户看按钮就知道点下去是什么效果，不靠文字或抽象符号猜。同理高亮/文字工具的可调属性如无特殊原因也用效果预览而非数值文字。
- 色板 16 色网格（教程常用高饱和色 + 黑白灰），默认选中色由"标注主题"驱动；最近用过的 5 色排最前。
- 保存路径：与原图同目录同名 + `-ann.png`；已存在则 `-ann2.png`，依次递增。覆盖层上保存 = 存盘 + 进剪贴板，一次动作两个结果。
- 属性行右侧常驻一行说明：「标注主题：教程红 · 改动自动记住为默认（可在「标注主题」页关闭）」；选择工具的属性行提示同步写明记忆机制。界面上不出现"只改本次"这类与记忆模型矛盾的旧文案。
- 未保存离开：拦一次，三选一（保存 / 不保存 / 取消）。
- 撤销栈 20 步，`⌘/Ctrl+Z` 撤销、`⇧⌘/Ctrl+Shift+Z` 重做。
- **设置与记忆（对齐 同类产品"记住上次"模型）**：编辑器是标注样式的**唯一调参入口**。任何参数改动（颜色、线宽、字体、粗斜体、阴影、对齐、行距、马赛克强度、序号样式与起始值）自动"记住上次"，成为下次打开的默认值；「标注主题」页只是这份数据的管理视图（查看/恢复默认/导出预设），不提供第二套参数。通用设置里一个开关"记住标注设置"可整体关闭（关闭后改动仅本次生效，默认值不再更新）。
- 编辑 Agent 生成的衍生图时，编辑器顶部显示一行黄底提示"这是在 Agent 标注 v1 上继续编辑，保存将生成 v2"，让 lineage 对用户可见。
- 保存后 toast：「已保存标注 v2 · 5 个操作」，带"撤销保存"次级动作（3 秒内有效，实际是删除刚生成的衍生图，原图不受影响）。

### 4.8 标注主题（默认值管理视图）

**定位（定死，不再摇摆）**：调参入口在编辑器（§4.7），本页**只做管理，不做第二套参数**。页面展示的每一项都是编辑器自动记忆的"上次使用值"，用户在编辑器里改了什么，这里就显示什么——两边永远是同一份数据，Agent 脚本（G-5 预设）继承的也是这份数据。

| 箭头宽度 / 标签字号 | 滑杆（灰显禁用，只读展示记忆值） | 对应编辑器线宽 / 文字字号 |
| 文字字体 | 文本展示 | 编辑器字体下拉的记忆值 |
| 文字样式 | 文本展示（常规 / 加粗 / 斜体 / 下划线 / 阴影组合） | 编辑器 B/I/U/阴影的记忆值 |
| 文字对齐 / 行距 | 文本展示 | 编辑器对齐与行距的记忆值 |
| 矩形/椭圆样式 | 文本展示（描边 / 填充 / 描边+浅填充） | 形状工具记忆值 |
| 高亮不透明度 | 文本展示 | 高亮工具记忆值 |

| 序号样式 / 起始值 | 只读文本展示 | 序号工具记忆值 |
| 标注目标时自动绘制边框 | 开关（灰显禁用，展示记忆值） | 行为默认值随编辑器记忆 |
| Spotlight 暗化非目标区域 | 开关（灰显禁用，展示记忆值） | 行为默认值随编辑器记忆 |

**只读铁律**：除「记住标注设置」「恢复默认值」「导入 JSON / 导出预设」三个管理动作外，本页其余控件一律灰显禁用；**本页没有"保存"按钮**——默认值由编辑器自动记忆，这里看到的永远是最新的一份。页面底部注明这一点，用户不会找不到"保存"而困惑。

**预设与 Agent 的对应关系**（G-5 的价值点）：预设存成一个具名 JSON（如 `教程红`），Agent 的标注脚本可以写 `{"theme": "教程红"}`。这样人调一次，Agent 生成的图就自动是这个样子，两边不会各画各的。预设文件路径在页面上显示，方便 Agent 直接读。

### 4.9 Agent 与隐私

**顶部：Agent 与自动化（两个开关）**

- 「允许本机 Agent 调用定影」：40×22 开关，切换立刻生效（1 秒内 Agent 侧生效）。说明文字写明"CLI、Agent Skill 与 MCP 通过仅限当前用户的本机桥接调用，不开放网络端口"。
  - 开关下方状态行实时改文案：允许时绿色"当前状态：允许（Agent 可调用截图、OCR、标注）"；切断时红色"当前状态：已切断（截图类调用返回退出码 5，历史与状态查询不受影响）"。
  - 标题栏的 Agent 状态点与这里联动：绿点 / 红点。
  - 从允许切到切断时，若当前有活跃的 MCP 会话，给一条轻提示"已切断 · 正在进行的 Agent 调用会收到权限错误"。不弹窗打断。
  - 切断后，下面的「无感自动截图」开关置灰不可用（总闸没开，分闸无意义）。
- 「允许无感自动截图」：默认开。说明文字写明"静默截图不弹出取景层、不抢占前台 App、不模拟键鼠；黑名单与审计日志依旧生效"——即无感不等于绕过保护，黑名单命中照样退出码 6。

| 元素 | 规格 |
|---|---|
| 内置条目 | 1Password、Bitwarden、KeePass、LastPass、微信支付、各主要银行 App 等，带"内置"标签，可停用不可删除 |
| 自定义条目 | 输入框支持进程名（`1password.exe`）或通配关键字（`*银行*`），回车即添加 |

| 顶部一行说明 | "命中即拒绝截图，不留成图，Agent 收到退出码 6 的明确错误" |

**黑名单命中时的提示（G-3）**

覆盖层不出现，改为屏幕右下（macOS 右上）一条警告提示：

### 4.10 Agent 接入

这一页解决一个具体问题：**用户怎么确认自己真的接上了。** PRD 把这件事拆在 MCP-1~5、SKL-1~3、CLI 里，但没有界面。

**结构：状态条 + 三步 + 速查表**

**状态条**（顶部，横贯）

```text
桥接 正常监听   ·   Agent 最近调用 今天 14:32   ·   今日调用 27 次
```

未连接时显示"尚未被调用过"，这就是用户需要的答案。

**第 1 步 · 安装 CLI 与 Skill（一次装齐）**

- 卡片标题行右侧放两个检测徽标：「once CLI · 已检测」「once Skill · 已安装」，加「重新检测」按钮；检测未通过时徽标变黄并给出修复按钮。
- 副标题一句话讲清机制："一条命令同时安装或更新 CLI 与 Skill：自动校验下载文件，并适配 Codex 和通用 Agent Skills 目录。"
- 两种等价安装方式并排成两张卡（对齐参考产品的布局，用户挑顺手的那种）：

| 方式 | 内容 | 交互 |
|---|---|---|
| 方式一 · 终端 | 一条安装命令（`curl … install.sh \| bash`，带重试参数） | 「复制」按钮，点击复制整条命令 |
| 方式二 · 交给 Agent | 一段完整安装提示词，用户整段粘给任何 Agent 代为执行 | 「复制」按钮，复制多行提示词 |

- 安装提示词模板（文案随版本可调）：

```text
请帮我在这台电脑安装 OnceGlance 的 CLI 和 Agent Skill。请执行下面这条命令：
curl -fsSL --retry 3 --retry-all-errors --retry-delay 1 https://github.com/wample/OnceGlance/releases/latest/download/install.sh | bash
安装完成后，运行 once status --json 验证是否安装成功。
```

- 卡片底部一行小字："安装后重启 Agent，再运行 `once status --json` 验证连接。Windows 在 Git Bash / WSL 中执行，macOS 在终端执行。"
- 设计理由：让 Agent 替用户装工具，是"人负责操作，Agent 负责干活"分工的第一步——用户不需要懂命令行，也能把接入做完。

**第 2 步 · 配置 MCP**

- 按平台生成配置 JSON（路径为当前机器绝对路径），一个代码块 + 「复制配置」按钮。
- 复制后按钮变"已复制"，2 秒后复原。
- 代码块下方一行小字：「配置写到哪里」→ 展开显示 ZCode / Claude Code / Codex CLI 各自的配置文件路径与截图位置。

**第 3 步 · 跑一次自检（G-6）**

- 一个按钮「跑一次截图链路」，点后依次执行 `capture window → ocr last → annotate last`。
- 三行结果逐行亮起，每行显示耗时；全部通过显示"链路正常 · 三段耗时 1.2s / 0.9s / 0.3s"，并给"看看产物"打开刚生成的图。
- 失败时停在失败那一步，显示退出码和修复建议（这是全页最有价值的反馈）。

**接口速查表**

| 分区 | 内容 |
|---|---|
| 命令 | `once status / capture / ocr / annotate / history / open / config / doctor / mcp`，每行可复制 |
| 退出码 | 0–6 全部列出，右侧一列"什么时候会看到" |
| 输出约定 | 落盘目录、命名规则、envelope 结构，各一行 |

**兼容矩阵**：ZCode / Claude Code / Codex CLI / 其他 MCP 客户端，各一行标注接入方式与"已验证 / 未验证"。未验证的明确写"未验证"，不要假装都行。

### 4.12 诊断（doctor 的界面版）

**入口**：左导航第 6 项 · 托盘菜单"诊断" · 标题栏状态点（黄色/红色时点击直达）。

**结构**：一键自检 + 7 行结果 + 一键复制诊断报告。

| # | 检查项 | 通过 | 失败时的动作 |
|---|---|---|---|
| 1 | 实例状态 | 单实例正常运行 | "检测到另一个实例，已激活它" |
| 2 | 全局热键 | 6 个热键已注册 | 列出冲突的热键 + "重新注册"（能自动修的自动修） |
| 3 | 捕获自检 | 截取屏幕角落 64×64 并校验非全黑 | "重试" + 建议关掉可能拦截的杀软 |
| 4 | 落盘目录 | 可写、可创建日期子目录 | "更改目录" |
| 5 | OCR 引擎 | 用内置样图跑一次识别并比对 | "重试" / "换引擎"（P1 增强包到位后才有第二项） |
| 6 | 桥接监听 | Named Pipe / stdio 可用 | "重启桥接" |
| 7 | 权限（按平台） | macOS：屏幕录制 + 辅助功能；Windows：WebView2 运行时 | 各带"打开系统设置"深链接 |

**复制诊断报告**：生成一段纯文本，含版本、系统版本、屏幕布局（数量、分辨率、DPI 缩放）、7 项结果、最近 20 条审计元数据。**不含任何截图内容与 OCR 文字**（页面上写明这一点，用户才敢贴到 issue 里）。

**首次进入若无失败项**：显示"7 项全部正常"，配一行"上次自检 今天 15:12"。

### 4.13 通知与反馈体系

统一四类，全产品只有这四种提示，不再有第五种。

| 类型 | 何时用 | 停留 | 动作 | 退出码 |
|---|---|---|---|---|
| 轻提示 | 成功、状态变化 | 3 秒自动消失 | 无 | — |
| 警告 | 部分成功、可继续 | 5 秒 | 最多一个（如"调整黑名单"） | 有时带 |
| 错误 | 失败且用户要处理 | 不自动消失，需手动关闭 | "详情" / "重试" | 必带 |
| 进度 | 拼接、批量识别 | 出现到结束 | "取消" | — |

**结构**：状态点（7px）+ 文案 + 可选动作。文案公式 = **结果 + 数字 + 下一步**。

| 场景 | 文案 |
|---|---|
| 区域截图成功 | `已复制 · 本地完成` |
| 取字成功 | `已复制 216 字 · 本地完成` |
| 保存失败 | `保存失败（退出码 4）· 图片已在剪贴板，换个目录可重试` |
| OCR 无文字 | `未发现文字 · 已复制图片` |
| 黑名单拦截 | `已拦截：1Password · 隐私黑名单（退出码 6）` + 「调整黑名单」 |
| Agent 被切断 | `Agent 调用已拒绝（退出码 5）· 在「Agent 与隐私」里开启` |
| 剪贴板被占用 | `剪贴板已有新内容，文字已保存至 …\143012-window-a1b2.txt` |
| 长截图完成 | `长截图已保存 · 12 段 · 12480px` |
| 多张连续截图 | `已保存 3 张 · 已复制最后一张`（5 秒内合并计数，不堆 3 条） |

**位置**：Windows 右下贴任务栏上方 12px；macOS 右上贴菜单栏下方 12px；有捕获覆盖层时，提示落在**光标所在的屏幕**的对应角落（不是主屏），否则跨屏工作时用户看不见。

**错误级在 macOS 额外发一条系统通知**：菜单栏应用随时可能被别的窗口盖住，错误必须能穿出来。仍是本地通知，不涉及任何上报。

**不抢焦点**：所有提示 `role="status"`，读屏可播报；不拦截鼠标；不自动获得焦点。

## 6. 状态、加载与空态

| 状态 | 表现 |
|---|---|
| OCR 进行中 | 卡片 OCR 预览处显示"识别中…"+ 呼吸点；详情页文字块区显示骨架行 |
| 捕获中（延时/拼接） | 进度类提示，带"取消" |
| 首次无数据 | 各页统一空态：一句话说明 + 一个主动作按钮 |
| 目录不可写 | 设置页路径 chip 变红；截图时错误级提示 + 退出码 4 |
| Agent 未接入 | 接入页显示"尚未被调用过"，不显示任何红色错误（没接入是正常状态，不是故障） |
| 热键冲突 | 设置页该项标黄 + 顶部一条汇总"1 个热键未生效"，托盘菜单对应项也标黄 |
| 诊断有失败项 | 标题栏状态点变黄/红，可点直达 |

**动画**：只用透明度与位移，150–220ms；尊重系统"减少动态效果"；toast 三平台移动方向不同（Windows 从下往上，macOS 从上往下）。
