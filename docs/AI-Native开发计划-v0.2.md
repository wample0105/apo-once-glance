# 定影 v0.2.0「AI Native」开发计划（PRD）

> 状态：**待用户确认后开工**。本文档为 v0.2.0 的功能定义、架构设计与里程碑计划。
> 规格参考：同类产品的 AI 模型配置 / 截图翻译 / 识别引擎界面。

---

## 1. 背景与目标

### 1.1 变化

v0.1.x 的核心承诺是「零 API Key、零云端上传」——它换来了极简分发与隐私口碑，但也把 AI 能力锁死在了「本地 OCR（Windows.Media.Ocr）+ Agent 三端接入」上：识别有错别字、没有翻译、没有问图，普通用户（不接 Agent 的人群）无法使用任何 AI 能力。

**v0.2 放弃该承诺，转向「本地优先、云端 opt-in（BYOK）」**：

- **本地优先**：不配置任何 AI 模型时，全部既有功能照常工作（本地引擎取字等）；
- **云端 opt-in**：用户自行配置 AI 服务商（API Key），AI 增强功能按需解锁；
- **隐私铁律不变**：API Key 加密存本机；**只有用户主动触发，才发送截图**；AI 调用全部入审计日志。

### 1.2 目标

1. 普通用户：按键即可用上翻译 / 问图 / 高质量识别（配置一次 Key）；
2. Agent 用户：三端获得 AI 能力（`once translate` / `once ask` / MCP 新工具）——三端同源是定影区别于同类产品（仅有 GUI）的差异化；
3. 包体不膨胀：云端能力零模型文件；本地 OCR 增强（RapidOCR）走按需下载。

## 2. 功能定义（四件套 + 增强包 + 三端）

### F1 AI 模型配置中心（地基，M1）

主面板新增一级导航「**AI**」页（信息架构见第 3 章），三步向导：**选择服务商 → 填 API Key → 测试并保存**。

| 项 | 设计 |
|----|------|
| 第一批服务商（OpenAI 兼容协议，一个 client） | **智谱**（置顶推荐，glm-4.5v 视觉+文字）/ **DeepSeek**（文字，翻译场景）/ **OpenRouter**（聚合）/ **自定义 OpenAI 兼容端点**（base_url + key + model 自填） |
| 第二批服务商（独立适配器，M4） | Gemini、Claude（原生协议） |
| 配置字段 | 名称 / 服务商 / base_url / api_key / **文字模型** / **视觉模型** |
| 多配置 | 可存多套；「默认文字模型」「默认视觉模型」两个角色分别指定 |
| Key 存储 | **Windows 凭据管理器**（加密存储；设置文件只存非敏感字段）——业界对标：同类产品存 macOS 系统凭据库（Keychain） |
| 测试连接 | 文字模型发最小对话；视觉模型发 1×1 图；双向验证 |

> 架构说明：**翻译走「本地 OCR 提取 + 文字模型翻译」**（省 token、文本准确，DeepSeek 这类纯文字模型也能用）；**问图 / 云端 OCR 走视觉模型**（读图）。因此「文字/视觉」两栏分开配置是必要的。

### F2 AI 问图（框选 → 自然语言，M2）

- 取景层工具条「AI」菜单（见第 3 章）新增「**问图**」；
- 交互：点击 → 输入框浮层（**预置指令 chips**：解释这段内容 / 提取成 Markdown 表格 / 总结要点 / 翻译成中文 + 用户自定义模板 + 自由输入）→ 发送（选区截图 + 问题，视觉模型）→ **结果浮窗**（复制 / 重试 / 关闭）；
- **自定义指令模板**：设置页管理（名称 + Prompt 模板），出现在 chips 中——同类工具的自定义 AI 指令 模式，是 AI Native 的灵魂功能；
- 模型：默认视觉模型，浮窗内可临时切换。

### F3 截图翻译（M2）

- 取景层工具条「AI」菜单新增「**翻译**」；
- 流程：**本地 OCR 提取** → 文字模型翻译（源语言自动检测/指定，目标语言默认简体中文）→ 结果浮窗（复制）；
- 翻译设置页：源/目标语言、默认行为（v0.2 = 翻译并复制）；
- backlog：贴图式替换翻译（文字擦除并替换回图，工程量大）。

### F4 云端 OCR 增强（M3）

- 触发：取字时**用户主动**选「AI 增强」，或本地 OCR 失败时提示（不静默上传）；
- 实现：视觉模型 +「提取图中全部文字」指令，输出纯文本（**无 bbox**）；
- 边界：`once ocr`（Agent 依赖 bbox）仍走本地引擎；云端增强仅面向人的取字/问图；
- 设置归入「AI」页「识别」节：识别方式说明 + 隐私文案（「普通识别始终在本机完成」「只有主动增强时才发送截图」）。

### F5 RapidOCR 按需增强包（本地质量升级，M3.5）

| 项 | 设计 |
|----|------|
| 获取 | 设置页点击下载（**默认不打包、不增主包体积**）；模型约 16MB（det 4.7MB + rec 10.5MB + 字典） |
| 下载源 | 设置可选：**魔搭 ModelScope（默认，国内直连）/ HuggingFace**；两源同一文件同 SHA-256；失败提示一键切换（不静默自动切换） |
| 校验与存放 | SHA-256 校验；存放 `%LOCALAPPDATA%\Onceglance\models\`（Tauri app_local_data_dir；三端共享；`ONCE_MODELS_DIR` 环境变量覆盖适配便携部署）；设置页管理（版本 / 删除 / 打开目录） |
| 引擎优先级 | **RapidOCR（已下载）> Windows.Media.Ocr（内置兜底）> 云端增强（主动触发）** |
| 红利 | RapidOCR 输出**真实置信度**——解决 Windows.Media.Ocr 恒 1.0 的老问题，「本地低置信 → 提示云端增强」闭环成立 |
| 技术要点 | `ort`（onnxruntime Rust 绑定）+ DBNet/CrNN 前后处理（有 RapidOCR 参考实现）；v0.2 内工程量最大单项 |

### F6 三端打通（M3）

- **CLI**：`once translate --to zh [-i <img>|last]`、`once ask --prompt "..." [-i <img>|last]`、`once model list|test`；
- **MCP**：新增工具 `translate_image`、`ask_image`；
- **配置共享**：CLI/MCP 读同一凭据库与设置；支持 `ONCE_MODELS_DIR` 等覆盖。

## 3. UI 与信息架构设计

> 2026-09-25 定案（四项均按业界最佳实践推荐项拍板）。三原则：**克制**（不无计划堆按钮）、**分组**（扩展能力收进菜单）、**复用**（不新增窗口类型，能复用现有组件就不新造）。

### 3.1 主面板：新增一级「AI」导航页

- 左侧导航 5→6 项：**首页 / AI / Agent / 标注主题 / 通用 / 诊断**；「AI」紧随首页，呼应 v0.2 产品身份；
- 「AI」页三节，全部复用现有 group/row/switch 设置组件：
  1. **模型**：服务商选择（智谱置顶推荐 / DeepSeek / OpenRouter / 自定义端点）+ API Key（写入系统凭据库，界面不回显明文）+ **文字模型 / 视觉模型双栏** + 「测试连接」+ 默认角色指定，支持多套配置；
  2. **识别**：引擎优先级说明（RapidOCR > 系统内置 > 云端增强）、RapidOCR 增强包管理（下载来源魔搭（默认）/ HuggingFace、版本、删除、打开目录）、隐私文案（「普通识别始终在本机完成」「只有主动增强时才发送截图」）；
  3. **指令模板**：问图自定义 chips 管理（名称 + Prompt，增删改与排序）；
- **通用页「关于」改写**：「零云端承诺：零 API Key · 零上传 · 零遥测」→「隐私：本地优先 · 云端增强须主动开启 · Key 加密存本机 · AI 调用入审计日志」；
- 诊断页自检项扩展：模型连接（已配置时）、增强包状态。

### 3.2 取景层工具条：单「AI」按钮 + 弹出菜单

- 现有 4 组 19 钮布局**不动**；在「取字」右侧**净增 1 个「AI」按钮**，点击弹出菜单：**翻译 / 问图**（M3 起追加「AI 增强识别」）；
- 菜单复用形状按钮已验证的 slot-menu 交互模式；未来 AI 能力统一收进此菜单，工具条不随功能横向生长；
- 点「问图」→ 选区保留 → 输入浮层（预置 chips：解释内容 / 提取表格 / 总结要点 / 翻成中文 + 自定义模板 + 自由输入）→ 发送。

### 3.3 结果呈现：复用贴图窗口

- 翻译 / 问图 / 云端 OCR 的结果一律生成为**「结果贴图」**：复用现有贴图窗的阴影、置顶、拖动、缩放、关闭全套交互，**零新窗口类型**；
- 结果贴图内提供复制 / 重试 / 关闭；问图可在贴图内临时切换模型；
- 结果贴图不写入截图历史（保持贴图「即用即走」语义）；AI 调用元数据照常入审计日志。

### 3.4 未配置引导：就地迷你卡片

- 未配置 Key 就点 AI 动作时：**选区保留**，就弹出迷你引导卡（选服务商 → 贴 Key → 「测试并继续」），成功后**直接执行刚才点的动作**；「稍后再说」收束到主面板「AI」页；
- 卡片附一句隐私说明：「只有你主动触发，才会发送截图」。

### 3.5 UI 不做清单

- 首页不加 AI 卡片（入口在工具条与导航，动作区不膨胀）；
- 工具条不平铺多个 AI 按钮；不为 AI 结果新增窗口类型；不做「AI 结果」历史页。

## 4. 隐私与安全设计

1. **Key**：Windows 凭据管理器存储；不做「导出全部配置」功能（防批量提取）；
2. **opt-in**：所有网络 AI 调用由用户主动动作触发，无任何静默上传；
3. **审计**：AI 调用入审计日志（时间 / 动作 / 服务商 / 模型 / 是否发送图像）——沿用现有审计体系，隐私透明化是差异化加分；
4. **文案重写**：
   - README：「本地三零」→「**本地优先**：默认全功能本地可用；AI 增强 BYOK 可选——Key 加密存本机，只有主动触发才发送截图」；
   - 设置页/首启提示同步；徽章、Release 说明同步。

| 里程碑 | 交付 | 验收标准 |

| **M1 地基** | AI 模型配置中心（设置页 UI + 凭据存储 + OpenAI 兼容 client + 测试连接）+ 隐私文案重写 | 配置智谱 Key → 测试绿灯 → 重启后配置持久且 Key 不在明文文件 |

| **M4 收尾** | Gemini/Claude 适配器 + README/教程更新 + Release v0.2.0 | 全功能回归 + Release 发布（GUI/CLI/安装脚本） |

## 6. 不做清单（v0.2 明确不做）

- 贴图式替换翻译（文字擦除并替换回图）；
- 自然语言检索历史、AI 消除/生图；
- AI 语义整理（自动命名/标签/摘要）——候选 v0.3；
- 内嵌聊天机器人。

## 7. 风险与开放问题

1. Rust 侧引入 `reqwest`（HTTP）依赖：编译体积与复杂度增加——评估用 tauri 已有栈或轻量 `ureq`；
2. 凭据管理器在 windows-rs 的绑定成熟度——有 `keyring` crate 可直接用；
3. 视觉模型对「结构化提取类指令」的格式遵从不稳定——用 JSON mode / 提示词强约束兜底；
4. M3.5 的 ONNX 前后处理（DBNet 后处理）工作量——有 RapidOCR 开源参考实现，风险可控。
