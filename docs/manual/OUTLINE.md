## 写作总则

1. **受众**：主线面向小白用户（按顺序读即可上手）；附录为参考区（按需查阅）。
2. **语言**：中文；讲后果不讲机制；界面描述一句封顶；操作步骤用「按 X → 出现 Y → 点 Z」的任务句式。
3. **版本基线**：v0.1.1 已发布功能；未实现功能（如窗口吸附）一律不写；依赖发版的能力（Skill 安装）标注「需 v0.1.2+」。
4. **配图**：全部用定影自家产线（`once capture` 采集 → `once annotate` 标注），统一风格：红色主标注 + 圆形序号，既是教程也是标注引擎验收（dogfooding）。
5. **每章结构**：开头一句话「这章学会什么」→ 正文 → 结尾「下一步」链接到后一章。
6. **快捷键呈现**：正文只出现高频键（Alt+Shift+A、Enter、D、Ctrl+Z 等），完整键位表一律指向附录 A，避免正文淹没。
7. **口径同源**：全局热键表、退出码表、MCP 工具清单、安装命令以 README 门面为同源基准，教程与 README 不允许出现两套说法；README 未覆盖的细节以代码实测为准。

## 01 认识定影（10 分钟）

- 定影是什么：一句话「给人用的截图工具，也是 AI Agent 的眼睛」。
- 四大能力一览表：截图标注 / 长截图 / 贴图 / 取字 OCR（各一句 + Agent 三端一句话）。
- 隐私一句话：全程本地处理，不上传任何图片与文字。
- 全局热键总表（与 README 门面同源，6 个）：`Alt+Shift+A` 区域截图 / `Alt+Shift+W` 窗口截图 / `Alt+Shift+F` 全屏截图 / `Alt+Shift+T` 自动取字 / `Alt+Shift+L` 长截图 / `Alt+Shift+H` 打开主面板；截图内与编辑器快捷键指向附录 A。
- 配图：主面板首页全景（序号标注：动作卡 / 最近截图 / 左侧导航）。

## 02 第一张截图（教程）

- 按下 `Alt+Shift+A` 后发生什么：屏幕定格并变暗。
- 认识取景层三个助手：**自动识别框**（悬停自动亮起窗口/控件边界）、**放大镜**（像素坐标 + 取色 HEX）、**尺寸牌**（实时宽高）。
- 三种选法：**点一下**＝自动选中窗口或控件；**拖拽**＝自由框选；`Esc`＝取消。
- 提交：`Enter`＝复制到剪贴板 → 去微信/Word 粘贴验证。
- 其他出口：`Ctrl+S` 快存、💾 按钮＝另存为（选位置）、✕ ＝退出。
- 一键变体：全屏 `Alt+Shift+F`、活动窗口 `Alt+Shift+W`（免框选直接出图）。
- 配图：取景层初始态（识别框+放大镜）；框选完成态（动作条按钮逐一标注）。

## 03 给截图加标注（教程）

- 框选后直接画：工具栏位置 + 每个工具一句话（箭头/矩形/椭圆/画笔/荧光笔/文字/序号/马赛克/橡皮擦/裁剪）。
- 任务式上手（每任务 3-5 步）：
  1. 加红色箭头指重点（拖出箭头，`Shift` 锁 45°）；
  2. 给步骤加序号（连点自增 ①②③，`Alt` 复用同一号）；
  3. 遮住敏感信息（马赛克/模糊，遮哪糊哪，可拖动）;
  4. 写字说明（文字 + 背景色块，描边自动反色保证可读）。
- 改到满意为止：单击选中 → 拖动移动 / 手柄缩放 / ◎ 旋转 / 属性行随手改 / `×` 删除 / `Ctrl+Z` 撤销——保存前一切可改。
- 输出：`Enter`＝复制成品（标注自动合成）；保存按钮＝弹对话框选位置；成品与原图都进历史。
- 配图：编辑器全景（工具栏+属性行+状态栏标注）；标注实战成品图（箭头+序号+马赛克+文字同图）；选中编辑态（手柄+旋转锚+删除锚）。

## 04 长截图（教程）

- 什么时候用：聊天记录 / 长网页 / 列表存档。
- 两条进入路径：取景层内点长图按钮（或 `L` 键）；或直接按全局热键 `Alt+Shift+L` 框选即采。
- 流程：框选 → **慢慢匀速滚动** → 工具条点保存 / 贴图 / 复制。
- 两条注意：快滚会丢段（慢滚 100% 成功）；滚到底停一秒再点完成。
- 接缝自动处理，无需手动修图。
- 配图：长截图进行中（选区蓝框 + 下层页面在滚）；工具条特写（尺寸+四按钮）。

## 05 贴图（教程）

- 贴图是什么：把截图钉在屏幕最上层，随取随用。
- 贴出：框选后按 `D`（或 📌 按钮）——原位原大、四边阴影浮出，截图流程即结束。
- 摆弄一张贴图：拖动移动 / 滚轮缩放 / `Ctrl+滚轮` 调透明度（十档，中央显示百分比）/ 双击关闭。
- 场景：贴着聊天记录回消息；贴着参考图做设计；贴一段配置对照操作。
- 配图：屏幕上的贴图效果（阴影+透明度 HUD）。

## 06 历史与取字（操作指南）

- 每张截图自动入库：首页最近 8 张 →「查看全部」进全量历史。
- 找图：类型角标筛选 + 搜索语法各给一行示例（`kind:window` / `after:昨天` / `has:annotated` / `ocr:发票`）。
- 详情页：1:1 原图查看 / 适应窗口 / 滚轮缩放；**版本链**（原图 → 标注衍生图的脉络）。
- 卡片动作：复制 / 打开（系统看图器）/ 编辑（进编辑器继续改）。
- 取字：截图时点「取字」→ 本地 OCR，文字直接进剪贴板（不联网）。
- 配图：历史页全景；详情页（版本链区域标注）。

## 07 主面板与设置（设置指南）

- 五个页面各管什么（一张总表），逐页讲**概念 + 高频项**：
  - 首页：动作卡（区域截图 / Agent 接入）+ 最近截图。
  - Agent 页：权限总开关（关闭＝所有 AI 调用被拒）/ 无感自动截图开关 / App 黑名单（隐私防线）/ 审计日志（30 天自动清理）——接入步骤在 08 章，这里只讲开关语义。
  - 标注主题页：你的标注偏好（颜色/字体/序号样式…）会被 Agent 自动继承——这是定影特色；一键恢复默认。
  - 通用页：开机自启 / 托盘 / 落盘目录 / 截图退出确认 / 热键冲突提示。
  - 诊断页：一键自检 7 项，全绿即健康。
- 逐项参数的完整含义 → 附录 D（正文不罗列 30 项）。
- 配图：五页各一张小图（或两栏拼图控制篇幅）。

## 08 接入 AI Agent（教程 · 差异化核心）

- 解决什么问题：让 AI 助手看懂你的屏幕——截图、取字、标注全自动。
- 三种接入方式一览表：**WorkBuddy（最简，推荐）** / MCP 通用接入 / CLI 高级用法。
- 先讲一个安心前提：客户端没打开，Agent 也能调用（截图/取字/标注/历史检索不依赖常驻 GUI；仅交互式框选与长截图需要客户端在场）——与 README「三端同源、不依赖常驻」口径一致。
- **主线：WorkBuddy 三步**（copy-only 流程讲透）：① 复制接入配置（主面板 Agent 页一键复制）→ ② 到 WorkBuddy 设置里粘贴保存 → ③ 验证已接入（问 Agent「截一张当前屏幕」）。每步配图。
- 一键接入 MCP：主面板按钮 + 支持客户端说明（Claude Desktop / Claude Code / Cursor / Codex / ZCode 等，与 README 安装节同源；写入前自动备份原配置）。
- 验证与健康检查：`once status` / `once doctor` / 诊断页桥接状态（离线横幅含义）。
- 权限与隐私对 Agent 同样生效：总开关一关全部拒绝；黑名单命中直接拦截（退出码 6）。
- 其他客户端速查表（一节一张表）。
- FAQ：同家族桌面端与 CLI 端互不相通 / 接入后无响应排查路径。
- 版本标注：Skill 安装部分「需 v0.1.2+」。
- 配图：Agent 页一键接入区；WorkBuddy 配置粘贴位置；`once status` 验证输出。
